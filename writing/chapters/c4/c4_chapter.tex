\section{Experimental Setup}
All experiments follow a shared evaluation protocol for fair comparison across methods.

The experiments instantiate the student side with \textbf{SmolVLM-500M} and
\textbf{SmolVLM-256M}, evaluated on multimodal benchmarks
\cite{marafioti2025smolvlm}.

All models are evaluated with \textbf{VLM-Eval-Kit}
\cite{duan2024vlmevalkit}, which provides a shared inference,
post-processing and metric-computation pipeline for the three benchmarks. In
the experiments, the toolkit standardizes evaluation by loading each benchmark
split, applying the appropriate input template, running inference through a
unified model wrapper, normalizing the generated answers and computing the
dataset-specific score.

\section{Datasets}
We evaluate three text-centric VQA benchmarks: \textbf{TextVQA}, \textbf{DocVQA} and \textbf{ChartQA}.

These benchmarks test whether the model can \textbf{read visual text, understand questions and perform basic reasoning} across natural images, documents and charts. They were chosen because they cover complementary visual domains and combine OCR-heavy understanding with layout interpretation and numerical reasoning \cite{singh2019vqamodelsread,mathew2021docvqadatasetvqadocument,masry2022chartqabenchmarkquestionanswering}.

\subsection{Dataset Descriptions}
\textbf{TextVQA} \cite{singh2019vqamodelsread} evaluates question answering on natural images containing scene text.  
It focuses on reading scene text in natural images and combining it with
question understanding.
\textit{Sample question}: ``What word is written on the stop sign?''
\textit{Sample answer}: ``No word is visible on this sign.''

\textbf{DocVQA} \cite{mathew2021docvqadatasetvqadocument}: evaluates VQA on real document images (scans/photos), where layout, paragraphs, tables and forms are important.  
It emphasizes document structure understanding in addition to OCR.
\textit{Sample question}: ``What is the invoice number shown in this document?''
\textit{Sample answer}: ``4572.''

\textbf{ChartQA} \cite{masry2022chartqabenchmarkquestionanswering}: evaluates question answering over charts.  
It tests chart reading together with numerical and logical reasoning to derive the final answer.
\textit{Sample question}: ``Which year has the highest sales value in the chart?''
\textit{Sample answer}: ``The second (middle) bar has the highest value.''

\section{Training Configuration}

Unless otherwise stated, the main distillation experiments use a shared training
configuration so that differences in performance can be attributed to the
distillation strategy, not unrelated optimization choices.

We run all training jobs on a single high-memory \textbf{NVIDIA H200}
graphics processing unit (GPU) on \textbf{Modal} or on comparable single-GPU
\textbf{Vast.ai} instances, depending on availability.
A typical full H200 run takes about 7 hours and costs about 14.41 USD at
2.059 USD/hour on Vast.ai, excluding the separate cost of offline teacher-logit
generation and remote storage.
Distillation training uses \textbf{DeepSpeed ZeRO Stage 2}, \textbf{Brain
Floating Point 16 (bf16)} mixed precision, \textbf{TensorFloat-32 (TF32)}
matrix multiplication and gradient checkpointing to control memory use while
keeping the student fully trainable and all teachers frozen
\cite{rajbhandari2020zero,chen2016sublinear}.

Before training, we convert all benchmark samples into a unified
\textbf{LLaVA-style multimodal instruction format}
\cite{liu2023visualinstructiontuning}. Each example is stored as an image plus
a short user-assistant dialogue, so TextVQA, DocVQA and ChartQA can share the
same data loader, prompt template and answer supervision interface.

Listing~\ref{lst:llava-format} shows the structure used in our preprocessing
pipeline.

\section{Evaluation Metrics}
We report benchmark-specific official metrics for each dataset.

\paragraph{TextVQA.}
We report VQA Accuracy. For a predicted answer \(\hat{a}\), the
per-question score is
\[
s_{\text{VQA}}=\min\left(\frac{\#\text{annotators that provided } \hat{a}}{3},\,1\right),
\]
and the final score is the mean over all questions \cite{singh2019vqamodelsread}.

\paragraph{DocVQA.}
We report ANLS, the Average Normalized Levenshtein Similarity. The final ANLS
is the average score over all samples
\cite{mathew2021docvqadatasetvqadocument}:
\[
\mathrm{NLS}(a,\hat{a})=1-\frac{d_{\text{Lev}}(a,\hat{a})}{\max(|a|,|\hat{a}|)}, \quad
s_{\text{ANLS}}=
\begin{cases}
\mathrm{NLS}(a,\hat{a}), & \mathrm{NLS}\ge 0.5,\\
0, & \text{otherwise}.
\end{cases}
\]

\paragraph{ChartQA.}
We report Relaxed Accuracy. A prediction is correct if it matches exactly for
text answers. For numeric answers, the score handles the zero-target case
explicitly:
\[
s_{\mathrm{ChartQA}}=
\begin{cases}
\mathbf{1}[\hat{y}=y], & y=0,\\
\mathbf{1}\!\left[\frac{|\hat{y}-y|}{|y|}\le 0.05\right], & y\ne0.
\end{cases}
\]
The final ChartQA score is computed as the proportion of predictions that
satisfy either the exact text-match criterion or the relaxed numeric-match
criterion \cite{masry2022chartqabenchmarkquestionanswering}.

distillation baselines, different-family single-teacher baselines and
heterogeneous teacher baselines.

Before introducing the method-specific baselines, Table~\ref{tab:baseline-groups}
summarizes the role of each baseline family and separates student-only
references, same-family KD, tokenizer-mismatched single-teacher transfer and
heterogeneous teacher methods.

The non-distillation references consist of the original student and the
full-finetuning baseline, which provide student-only reference points. The
same-family baselines use \textbf{SmolVLM2-2.2B-Instruct} as teacher for
forward KL, reverse KL and Jensen-Shannon distillation, isolating standard
teacher-student transfer when the tokenizer and output space are matched
\cite{smolvlm2_modelcard,marafioti2025smolvlm,hinton2015distillingknowledgeneuralnetwork,lin1991jensen,cui2024sinkhorn}.
The different-family single-teacher setting uses ULD with a teacher outside
the SmolVLM family, testing tokenizer-mismatched transfer without teacher routing
\cite{boizard2024towardscrosstokenizerdistillation}. The heterogeneous
teacher setting compares uniform averaging, SHM-CKA, REINFORCE and
\methodname{} over a mixed teacher pool, separating static averaging,
hidden-state matching and adaptive teacher assignment
\cite{takezawa2021supervisedtreewasserstein,zhang2023adaptivemultiteachermetalearning,yu2024selectdistill,dasgupta2025improving}.

For the trainable competitor methods, we keep the supervised term
\(\mathcal{L}_{CE}\). The logits-only baselines differ only in the KD signal,
but SHM-CKA also adds a hidden-state alignment term and REINFORCE
also adds a REINFORCE-style policy term
\cite{kornblith2019similarityrepresentations,williams1992simple,yuan2020reinforcedmultiteacherselection}.
In the descriptions below, \(\gamma\) denotes a generic KD mixing coefficient.
\(\alpha\) remains reserved for the repository training script in
Table~\ref{tab:training-configuration}.

\paragraph{Original.}
The original setting directly evaluates the released student without
additional optimization, thereby measuring the native capability of the student
model before task adaptation or distillation.

\paragraph{Full finetuning.}
Full finetuning optimizes only \(\mathcal{L}_{CE}\) and uses no teacher, which
isolates the effect of supervised task adaptation from any teacher-guided
distillation signal.

\paragraph{Forward KL.}
Forward KL uses the standard same-family KD objective
\[
\mathcal{L}_{KD}=\mathrm{KL}(p_t\|p_s).
\]
This tests soft-target transfer in the matched-tokenizer setting where teacher
and student vocabularies are aligned
\cite{hinton2015distillingknowledgeneuralnetwork}.

\paragraph{Reverse KL.}
Reverse KL uses \(\mathcal{L}_{KD}=\mathrm{KL}(p_s\|p_t)\)
\cite{cui2024sinkhorn,wen2023fdistill} as a student-centered divergence
baseline, which tests whether matching the teacher from the student's current
distribution is suitable for VLM distillation. Because the reverse-KL gradient
is weighted by \(p_s\), this objective tends to emphasize regions where the
student already assigns probability.

\paragraph{Jensen-Shannon.}
Jensen-Shannon uses the symmetric divergence
\[
\frac{1}{2}\mathrm{KL}(p_s\|m)+\frac{1}{2}\mathrm{KL}(p_t\|m),
\qquad
m=\frac{1}{2}(p_s+p_t).
\]
It tests whether a bounded symmetric objective is more stable than KL
\cite{lin1991jensen,cui2024sinkhorn}.

\paragraph{ULD.}
ULD uses \(\mathcal{L}_{KD}=\|\pi(p_s)-\pi(p_t)\|_1\)
\cite{boizard2024towardscrosstokenizerdistillation}. This is the main
tokenizer-mismatched logits baseline because it compares ranked probability mass,
not token IDs.

\paragraph{SHM-CKA.}
SHM-CKA keeps the heterogeneous teacher set used by \methodname{}, but
replaces routed weighting with a per-teacher ULD logits loss plus a
hidden-state CKA penalty
\cite{boizard2024towardscrosstokenizerdistillation,dasgupta2025improving,kornblith2019similarityrepresentations}.
It tests whether direct representation alignment is sufficient without routed
\methodname{} weighting. This baseline separates representation matching from
output-level teacher selection.

\paragraph{Uniform multi-teacher.}
Uniform multi-teacher distillation assigns fixed equal weights to all teachers
in the heterogeneous pool,
\(\mathcal{L}_{KD}=\frac{1}{M}\sum_{i=1}^{M}\mathcal{L}_{KD}^{(i)}\)
\cite{yuan2020reinforcedmultiteacherselection,zhang2023adaptivemultiteachermetalearning},
thereby testing whether teacher diversity alone is sufficient without adaptive
routing or gradient-aware weighting.

\paragraph{REINFORCE.}
REINFORCE replaces deterministic routing with a stochastic policy that samples
teachers and updates the selector with REINFORCE
\cite{williams1992simple,yuan2020reinforcedmultiteacherselection}, providing
an adaptive routing baseline that does not use the gradient-agreement
refinement introduced by \methodname{}.

For SHM-CKA, the baseline implementation first loads an offline CKA matrix
and, for each student layer \(s\), selects the top-\(k\) teacher layers
\(\mathcal{T}_s\). Their CKA scores are normalized into soft weights
\(\alpha_{s,t}\). The per-teacher layer loss is
\begin{equation}
\mathcal{L}_{\mathrm{layer}}^{(i)}
=
\frac{1}{|S|}
\sum_{s \in S}
\sum_{t \in \mathcal{T}_s}
\alpha_{s,t}\bigl(1-\sqrt{\mathrm{CKA}(\mathbf{H}_s,\mathbf{H}_t)}\bigr).
\end{equation}
Each teacher also contributes its own ULD logits loss
\(\mathcal{L}_{\mathrm{ULD}}^{(i)}\). In the original single-teacher implementation, the
default fixed-weight objective gives equal weight to CE, logits KD and layer
matching:
\begin{equation}
\mathcal{L}_{\mathrm{fixed}}
=
\frac{1}{3}
\left(
\mathcal{L}_{CE}
+
\mathcal{L}_{\mathrm{ULD}}
+
\mathcal{L}_{\mathrm{layer}}
\right).
\end{equation}
That implementation also supports an alternative adaptive weighting scheme, but
the fixed equal-mean form above is the default setting. The original soft
top-\(k\) matching implementation was designed for single-teacher runs. For the
heterogeneous baseline used here, we preserve the hidden-state matching idea for
each teacher and average the logits and layer-matching terms across teachers:
\begin{equation}
\bar{\mathcal{L}}_{\mathrm{ULD}}
=
\frac{1}{M}\sum_{i=1}^{M}\mathcal{L}_{\mathrm{ULD}}^{(i)},
\qquad
\bar{\mathcal{L}}_{\mathrm{layer}}
=
\frac{1}{M}\sum_{i=1}^{M}\mathcal{L}_{\mathrm{layer}}^{(i)},
\end{equation}
then applies an equal-mean combination
\begin{equation}
\mathcal{L}_{\mathrm{SHM\text{-}CKA}}
=
\frac{1}{3}
\left(
\mathcal{L}_{CE}
+
\bar{\mathcal{L}}_{\mathrm{ULD}}
+
\bar{\mathcal{L}}_{\mathrm{layer}}
\right).
\end{equation}

For REINFORCE, the policy uses the pooled student hidden state
as a sample descriptor, then concatenates per-teacher summary features:
\begin{equation}
\mathbf{z}
=
\operatorname{Concat}\!\left(\mathrm{Pool}(\mathbf{H}_s),\mathbf{f}_1,\dots,\mathbf{f}_M\right),
\qquad
\mathbf{f}_i
=
\bigl[\mathcal{L}_{KD}^{(i)},\ c_i,\ e_i\bigr],
\end{equation}
where \(c_i\) is the teacher's mean token confidence and \(e_i\) is its
normalized token entropy over supervised positions. A linear policy then
predicts independent Bernoulli probabilities
\begin{equation}
\boldsymbol{\pi}=\sigma\!\left(W\,\mathrm{LN}(\mathbf{z})+b\right).
\end{equation}
During the warmup stage, all teachers stay active. After warmup, the baseline
samples \(m_i \sim \mathrm{Bernoulli}(\pi_i)\), falls back to the
highest-probability teacher if \(\sum_i m_i=0\) and normalizes the selected
mask into weights
\begin{equation}
w_i=\frac{m_i}{\sum_{j=1}^{M} m_j}.
\end{equation}
The multi-teacher KD term is the weighted average
\begin{equation}
\mathcal{L}_{KD}
=
\sum_{i=1}^{M} w_i \mathcal{L}_{KD}^{(i)}.
\end{equation}
In the REINFORCE training configuration, \(\mathcal{L}_{KD}^{(i)}\) is the per-teacher
trie-Wasserstein loss. The selector is trained with a REINFORCE-style term
\begin{equation}
\mathcal{L}_{\mathrm{pol}}
=
-(r-b)\log p(\mathbf{m}\mid\boldsymbol{\pi}),
\end{equation}
where \(b\) is an EMA reward baseline. The REINFORCE training configuration uses
\(r=-\mathcal{L}_{CE}-\frac{1}{\sum_i m_i}\sum_i m_i\mathcal{L}_{KD}^{(i)}\),
so the total reinforced-selection objective is
\begin{equation}
\mathcal{L}_{\mathrm{RS}}
=
\mathcal{L}_{CE}
+ \gamma \mathcal{L}_{KD}
+ \lambda_{\pi}\mathcal{L}_{\mathrm{pol}}.
\end{equation}

Unless noted otherwise, all baselines reuse the data conversion pipeline,
hardware, optimizer family and checkpointing protocol described earlier in
this chapter. Methods that do not use routing simply omit the GRACE-specific
terms and retain the corresponding single-teacher or uniform multi-teacher
objective from the cited source.

\section{Implementation Details}
\label{sec:implementation-notes}

This section records the engineering details needed to reproduce the main
training configuration. These details are useful for systems reproducibility, but they are
separate from the fair-comparison protocol summarized earlier.

\subsection{Offline Teacher-Logit Preparation}
Teacher logits are generated \emph{offline} before distillation. An offline
caching script runs each frozen teacher on every training example, keeps only
the supervised answer-token positions and writes one \texttt{.pt} file per
sample under a teacher-specific directory. Each record stores the sample index,
the selected teacher logits and the corresponding supervised labels. This
keeps the online training loop simple: the student only reads precomputed
teacher targets instead of running the teachers again.

After generation, the teacher-logit directories are uploaded to a
\textbf{Cloudflare R2} bucket using its S3-compatible object-storage interface
\cite{cloudflare_r2_overview,cloudflare_r2_s3}. In the active setup, the bucket
already exceeds \textbf{1 TB}, so copying the full cache to an external GPU
instance is impractical. This is especially relevant on services such as
Vast.ai, where local NVMe space is usually much smaller than the full teacher
logit store.

\subsection{Remote Logit Streaming During Training}
The main training path does \emph{not} download the full cache before training. When
the launcher receives an R2 root in
\texttt{distill\_multi\_teachers.sh}, the trainer switches to remote lazy
loading. During training, \texttt{StreamingTeacherLogitsCache} resolves the
teacher-specific remote object path
\[
\texttt{remote\_root}/\texttt{<dataset>\_teacher\_logits\_<alias>}/\texttt{<teacher-slug>}/\texttt{<index>.pt},
\]
then fetches files lazily from R2 through \texttt{s3fs} and
\texttt{WholeFileCacheFileSystem} \cite{fsspec_features,fsspec_api}. The
repository also includes a repacking utility for MDS, but the active
training path reads the raw per-sample \texttt{.pt} cache directly.

To keep disk usage bounded, the loader uses a \textbf{100 GB} local cache. The
loader caches each file only after first access, updates its access time after
opening and removes the oldest files first once the cache exceeds the limit.
In effect, the local cache behaves as a small least-recently-used style buffer
over the much larger R2 store. A per-teacher file lock also guards cache
metadata updates, so concurrent dataloader workers do not corrupt the cache
state.
