\section{Experimental Setup}
All experiments follow a shared evaluation protocol for fair comparison across methods. The study focuses on the two compact student models, \textbf{SmolVLM-500M} and \textbf{SmolVLM-256M}, evaluated on text-rich multimodal benchmarks. All model evaluations are conducted using \textbf{VLM-Eval-Kit} \cite{duan2024vlmevalkit}. In brief, the toolkit works as follows:
\begin{enumerate}
\item Load a benchmark split and apply its prompt template or input format.
\item Run model inference through a unified model wrapper interface.
\item Post-process raw generations into normalized answers.
\item Compute dataset-specific scores (e.g., VQA Accuracy, ANLS, Relaxed Accuracy) and aggregate final results.
\end{enumerate}
This unified pipeline ensures a consistent evaluation procedure across all compared models.

\section{Datasets}
We evaluate on three text-centric VQA benchmarks: \textbf{TextVQA}, \textbf{DocVQA} and \textbf{ChartQA}.  
The main purpose is to measure whether the model can \textbf{read textual content in images, understand questions and perform basic reasoning} across different visual domains (natural scenes, scanned documents and charts). These datasets are selected because they require OCR-heavy understanding, cover complementary visual domains and include retrieval, layout understanding and numerical reasoning.

\subsection{Dataset Descriptions}

It focuses on reading text in-the-wild and combining it with question understanding.

\textit{Sample answer}: ``No word is visible on this sign.''

\section{Evaluation Metrics}
We report benchmark-specific official metrics for each dataset:
\begin{itemize}
\item \textbf{TextVQA}: \textbf{VQA Accuracy}. For a predicted answer \(\hat{a}\), the per-question score is
\[
s_{\text{VQA}}=\min\left(\frac{\#\text{annotators that provided } \hat{a}}{3},\,1\right),
\]
and the final score is the mean over all questions \cite{singh2019vqamodelsread}.

\item \textbf{DocVQA}: \textbf{ANLS} (Average Normalized Levenshtein Similarity):
\[
\mathrm{NLS}(a,\hat{a})=1-\frac{d_{\text{Lev}}(a,\hat{a})}{\max(|a|,|\hat{a}|)}, \quad
s_{\text{ANLS}}=
\begin{cases}
\mathrm{NLS}(a,\hat{a}), & \mathrm{NLS}\ge 0.5,\\
0, & \text{otherwise}.
\end{cases}
\]
The final ANLS is the average score over all samples \cite{mathew2021docvqadatasetvqadocument}.

\item \textbf{ChartQA}: \textbf{Relaxed Accuracy}. A prediction is correct if it matches exactly for text answers, or if the relative error is within \(5\%\) for numeric answers:
\[
\frac{|\hat{y}-y|}{|y|}\le 0.05.
\]
The final score is the proportion of correct predictions \cite{masry2022chartqabenchmarkquestionanswering}.
\end{itemize}

\section{Baselines and Compared Methods}
\textbf{Full finetuning.} This baseline updates all trainable parameters of the student VLM on the target training data. It provides a strong upper-baseline adaptation setting because the model is optimized directly for the downstream task without distillation constraints. The training objective is the standard supervised next-token prediction loss:
\begin{equation}
\mathcal{L}_{\text{FT}} = - \sum_{t=1}^{T} \log p_{\theta}(y_t \mid x, y_{<t}),
\end{equation}
where \(x\) denotes the multimodal input, \(y_t\) is the target token at step \(t\) and \(\theta\) denotes all trainable parameters of the model.
