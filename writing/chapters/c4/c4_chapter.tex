\chapter{Evaluation Methodology}
\label{chap:evaluation-methodology}

\section{Experimental Setup}
All experiments follow a shared evaluation protocol for fair comparison across methods.

The study focuses on two compact student models, \textbf{SmolVLM-500M} and \textbf{SmolVLM-256M}, evaluated on text-rich multimodal benchmarks \cite{marafioti2025smolvlm}.

We evaluate all models with \textbf{VLM-Eval-Kit} \cite{duan2024vlmevalkit}. In brief, the toolkit works as follows:
\begin{enumerate}
\item Load a benchmark split and apply its prompt template or input format.
\item Run model inference through a unified model wrapper interface.
\item Post-process raw generations into normalized answers.
\item Compute dataset-specific scores (e.g., VQA Accuracy, ANLS, Relaxed Accuracy) and aggregate final results.
\end{enumerate}
This unified pipeline ensures a consistent evaluation procedure across all compared models.

\section{Datasets}
We evaluate three text-centric VQA benchmarks: \textbf{TextVQA}, \textbf{DocVQA} and \textbf{ChartQA}.

The goal is to measure whether the model can \textbf{read textual content in images, understand questions and perform basic reasoning} across different visual domains \cite{singh2019vqamodelsread,mathew2021docvqadatasetvqadocument,masry2022chartqabenchmarkquestionanswering}.

We chose these datasets because they require optical character recognition (OCR)-heavy understanding, cover complementary visual domains and include retrieval, layout understanding and numerical reasoning \cite{singh2019vqamodelsread,mathew2021docvqadatasetvqadocument,masry2022chartqabenchmarkquestionanswering}.

\subsection{Dataset Descriptions}
\textbf{TextVQA} \cite{singh2019vqamodelsread}: evaluates question answering on natural images containing scene text.  
It focuses on reading text in-the-wild and combining it with question understanding.
\textit{Sample question}: ``What word is written on the stop sign?''
\textit{Sample answer}: ``No word is visible on this sign.''

\section{Training Configuration}

Unless otherwise stated, the main distillation experiments use a shared training
configuration so that differences in performance can be attributed to the
distillation strategy, not unrelated optimization choices.

We run all training jobs on a single high-memory \textbf{NVIDIA H200}
graphics processing unit (GPU) on \textbf{Modal} or on comparable single-GPU
\textbf{Vast.ai} instances, depending on availability.
A typical full H200 run takes about 7 hours and costs about 21 USD on
Vast.ai, excluding the separate cost of offline teacher-logit generation and
remote storage.
Distillation training uses \textbf{DeepSpeed ZeRO Stage 2}, \textbf{Brain
Floating Point 16 (bf16)} mixed precision, \textbf{TensorFloat-32 (TF32)}
matrix multiplication and gradient checkpointing to control memory use while
keeping the student fully trainable and all teachers frozen
\cite{rajbhandari2020zero,chen2016sublinear}.

Before training, we convert all benchmark samples into a unified
\textbf{LLaVA-style multimodal instruction format}
\cite{liu2023visualinstructiontuning}. Each example is stored as an image plus
a short user-assistant dialogue, so TextVQA, DocVQA and ChartQA can share the
same data loader, prompt template and answer supervision interface.

Listing~\ref{lst:llava-format} shows the structure used in our preprocessing
pipeline.

\begin{lstlisting}[basicstyle=\ttfamily\footnotesize,breaklines=true,frame=single,caption={Representative LLaVA-style sample used after dataset conversion.},label={lst:llava-format}]

  "image": "sample_000123.jpg",

  ]
}
\end{lstlisting}

\subsection{Offline Teacher-Logit Preparation}
Teacher logits are generated \emph{offline} before distillation. An offline
caching script runs each frozen teacher on every training example, keeps only
the supervised answer-token positions and writes one \texttt{.pt} file per
sample under a teacher-specific directory. Each record stores the sample index,
the selected teacher logits and the corresponding supervised labels. This
keeps the online training loop simple: the student only reads precomputed
teacher targets instead of running the teachers again.

After generation, we upload the teacher-logit directories to a
\textbf{Cloudflare R2} bucket using its S3-compatible object-storage interface
\cite{cloudflare_r2_overview,cloudflare_r2_s3}. In our setup, the bucket
already exceeds \textbf{1 TB}, so copying the whole cache to a rented GPU
instance is impractical. This is especially relevant on services such as
Vast.ai, where local NVMe space is usually much smaller than the full teacher
logit store.

\subsection{Remote Logit Streaming During Training}
The current main training path does \emph{not} predownload the full cache. When
the launcher receives an R2 root
\texttt{distill\_multi\_teachers.sh}, the trainer switches to remote lazy
loading. During training, \texttt{StreamingTeacherLogitsCache} resolves the
teacher-specific remote path
\[
\texttt{remote\_root}/\texttt{<dataset>\_teacher\_logits\_<alias>}/\texttt{<teacher-slug>}/\texttt{<index>.pt},
\]
then fetches files lazily from R2 through \texttt{s3fs} and
\texttt{WholeFileCacheFileSystem} \cite{fsspec_features,fsspec_api}. The
repository also includes a repacking utility for MDS, but the current main
training path reads the raw per-sample \texttt{.pt} cache directly.

To keep disk usage bounded, the loader uses a \textbf{100 GB} local cache. The
loader caches each file only after first access. After a file is opened, the
loader updates its access time. When the total cache size exceeds the limit,
the loader removes the oldest cached files first. In effect, the local cache
behaves as a small least-recently-used style buffer over the much larger R2
store. A per-teacher file lock also guards cache metadata updates, so
concurrent dataloader workers do not corrupt the cache state.

\end{figure}

\section{Evaluation Metrics}
We report benchmark-specific official metrics for each dataset:
\begin{itemize}
\item \textbf{TextVQA}: \textbf{VQA Accuracy}. For a predicted answer \(\hat{a}\), the per-question score is
\[
s_{\text{VQA}}=\min\left(\frac{\#\text{annotators that provided } \hat{a}}{3},\,1\right),
\]
and the final score is the mean over all questions \cite{singh2019vqamodelsread}.

\item \textbf{DocVQA}: \textbf{ANLS} (Average Normalized Levenshtein Similarity):
\[
\mathrm{NLS}(a,\hat{a})=1-\frac{d_{\text{Lev}}(a,\hat{a})}{\max(|a|,|\hat{a}|)}, \quad
s_{\text{ANLS}}=
\begin{cases}
\mathrm{NLS}(a,\hat{a}), & \mathrm{NLS}\ge 0.5,\\
0, & \text{otherwise}.
\end{cases}
\]
The final ANLS is the average score over all samples \cite{mathew2021docvqadatasetvqadocument}.

\item \textbf{ChartQA}: \textbf{Relaxed Accuracy}. A prediction is correct if it matches exactly for text answers, or if the relative error is within \(5\%\) for numeric answers:
\[
\frac{|\hat{y}-y|}{|y|}\le 0.05.
\]
The final score is the proportion of correct predictions \cite{masry2022chartqabenchmarkquestionanswering}.
\end{itemize}

Table~\ref{tab:baseline-groups} summarizes the role of each baseline family
before the method-specific descriptions below.

\begin{itemize}
\item \textbf{Non-distillation references.} The original student and the full-finetuning baseline provide the student-only reference points for each benchmark.
\item \textbf{Same-family baselines.} Forward Kullback-Leibler (KL), reverse KL and Jensen-Shannon divergence all use \textbf{SmolVLM2-2.2B-Instruct} as a same-family teacher \cite{smolvlm2_modelcard,marafioti2025smolvlm,hinton2015distillingknowledgeneuralnetwork,lin1991jensen,cui2024sinkhorn}. They isolate standard teacher-student transfer when tokenizer, vocabulary and output space are already matched.
\item \textbf{Different-family single-teacher baselines.} This group uses one teacher outside the SmolVLM family. ULD is the main cross-tokenizer logits baseline \cite{boizard2024towardscrosstokenizerdistillation}.
\item \textbf{Heterogeneous multi-teacher baselines.} This group uses teacher pools drawn from different VLM families. Uniform averaging keeps fixed equal weights. SHM-CKA adds hidden-state matching over the same pool. Reinforced selection learns a stochastic teacher policy with REINFORCE \cite{williams1992simple,yuan2020reinforcedmultiteacherselection}. \methodname{} adds sparse routing, trie-Wasserstein KD and alignment-aware reweighting \cite{takezawa2021supervisedtreewasserstein,zhang2023adaptivemultiteachermetalearning,yu2024selectdistill,dasgupta2025improving}.
\end{itemize}

For the trainable competitor methods, we keep the same supervised term
\(\mathcal{L}_{CE}\). The logits-only baselines differ only in the KD signal,
but SHM-CKA also adds a hidden-state alignment term and reinforced selection
also adds a REINFORCE-style policy term
\cite{kornblith2019similarityrepresentations,williams1992simple,yuan2020reinforcedmultiteacherselection}.
In the descriptions below, \(\gamma\) denotes a generic KD mixing coefficient;
\(\alpha\) remains reserved for the current repository training script in
Table~\ref{tab:training-configuration}.

The compared methods are:
\begin{itemize}
\item \textbf{Original}: direct evaluation of the released student, with no additional optimization. This measures the native capability of the compact model before any task adaptation or distillation.
\item \textbf{Full finetuning}: uses \(\mathcal{L}=\mathcal{L}_{CE}\) with no teacher, so it isolates the benefit of external supervision.
\item \textbf{Forward KL}: the standard same-family KD baseline, with \(\mathcal{L}_{KD}=\mathrm{KL}(p_t\|p_s)\) \cite{hinton2015distillingknowledgeneuralnetwork}. It tests soft-target transfer when tokenizer and vocabulary are already matched.
\item \textbf{Reverse KL}: uses \(\mathcal{L}_{KD}=\mathrm{KL}(p_s\|p_t)\) \cite{cui2024sinkhorn,wen2023fdistill}. This variant is more mode-seeking and serves as a deliberately harder divergence baseline.
\item \textbf{Jensen-Shannon}: uses the symmetric divergence \(\tfrac{1}{2}\mathrm{KL}(p_s\|m)+\tfrac{1}{2}\mathrm{KL}(p_t\|m)\), where \(m=\tfrac{1}{2}(p_s+p_t)\) \cite{lin1991jensen,cui2024sinkhorn}. It tests whether a bounded symmetric objective is more stable than KL.
\item \textbf{ULD}: uses \(\mathcal{L}_{KD}=\|\pi(p_s)-\pi(p_t)\|_1\) \cite{boizard2024towardscrosstokenizerdistillation}. This is the main cross-tokenizer logits baseline because it compares ranked probability mass, not token IDs.
\item \textbf{SHM-CKA}: keeps the same heterogeneous teacher pool as \methodname{}, but replaces routed weighting with a per-teacher ULD logits loss plus a hidden-state CKA penalty \cite{boizard2024towardscrosstokenizerdistillation,dasgupta2025improving,kornblith2019similarityrepresentations}. It tests whether direct representation alignment is sufficient without routed GRACE weighting.
\item \textbf{Uniform multi-teacher}: averages the heterogeneous teacher losses with fixed equal weights, \(\mathcal{L}_{KD}=\frac{1}{M}\sum_{i=1}^{M}\mathcal{L}_{KD}^{(i)}\) \cite{yuan2020reinforcedmultiteacherselection,zhang2023adaptivemultiteachermetalearning}. It isolates the effect of teacher diversity without adaptive assignment.
\item \textbf{Reinforced selection}: replaces deterministic routing with a stochastic policy that samples teachers and updates the selector with REINFORCE \cite{williams1992simple,yuan2020reinforcedmultiteacherselection}. This baseline is close in spirit to adaptive selection, but it does not use GRACE score refinement.
\end{itemize}

For SHM-CKA, the historical training code first loads an offline CKA matrix
and, for each student layer \(s\), selects the top-\(k\) teacher layers
\(\mathcal{T}_s\). Their CKA scores are normalized into soft weights
\(\alpha_{s,t}\). The per-teacher layer loss is
\begin{equation}
\mathcal{L}_{\mathrm{layer}}^{(i)}
=
\frac{1}{|S|}
\sum_{s \in S}
\sum_{t \in \mathcal{T}_s}
\alpha_{s,t}\bigl(1-\sqrt{\mathrm{CKA}(\mathbf{H}_s,\mathbf{H}_t)}\bigr).
\end{equation}
Each teacher also contributes its own ULD logits loss
\(\mathcal{L}_{\mathrm{ULD}}^{(i)}\). In the historical single-teacher code, the
default fixed-weight objective gives equal weight to CE, logits KD and layer
matching:
\begin{equation}
\mathcal{L}_{\mathrm{fixed}}
=
\frac{1}{3}
\left(
\mathcal{L}_{CE}
+
\mathcal{L}_{\mathrm{ULD}}
+
\mathcal{L}_{\mathrm{layer}}
\right).
\end{equation}
That code also supports an alternative adaptive weighting scheme, but the fixed
equal-mean form above is the default historical setting. The original soft
top-\(k\) matching path was implemented for single-teacher runs, so the
heterogeneous baseline in this thesis keeps the same hidden-state idea per
teacher, averages the logits and layer terms across the teacher pool,
\begin{equation}
\bar{\mathcal{L}}_{\mathrm{ULD}}
=
\frac{1}{M}\sum_{i=1}^{M}\mathcal{L}_{\mathrm{ULD}}^{(i)},
\qquad
\bar{\mathcal{L}}_{\mathrm{layer}}
=
\frac{1}{M}\sum_{i=1}^{M}\mathcal{L}_{\mathrm{layer}}^{(i)},
\end{equation}
then applies the same equal-mean combination
\begin{equation}
\mathcal{L}_{\mathrm{SHM\text{-}CKA}}
=
\frac{1}{3}
\left(
\mathcal{L}_{CE}
+
\bar{\mathcal{L}}_{\mathrm{ULD}}
+
\bar{\mathcal{L}}_{\mathrm{layer}}
\right).
\end{equation}

For reinforced selection, the policy uses the same pooled student hidden state
as a sample descriptor, then concatenates per-teacher summary features:
\begin{equation}
\mathbf{z}
=
\Bigl[\mathrm{Pool}(\mathbf{H}_s);\ \mathbf{f}_1;\dots;\mathbf{f}_M\Bigr],
\qquad
\mathbf{f}_i
=
\bigl[\mathcal{L}_{KD}^{(i)},\ c_i,\ e_i\bigr],
\end{equation}
where \(c_i\) is the teacher's mean token confidence and \(e_i\) is its
normalized token entropy over supervised positions. A linear policy then
predicts independent Bernoulli probabilities
\begin{equation}
\boldsymbol{\pi}=\sigma\!\left(W\,\mathrm{LN}(\mathbf{z})+b\right).
\end{equation}
During the warmup stage, all teachers stay active. After warmup, the baseline
samples \(m_i \sim \mathrm{Bernoulli}(\pi_i)\), falls back to the
highest-probability teacher if \(\sum_i m_i=0\) and normalizes the selected
mask into weights
\begin{equation}
w_i=\frac{m_i}{\sum_{j=1}^{M} m_j}.
\end{equation}
The multi-teacher KD term is the weighted average
\begin{equation}
\mathcal{L}_{KD}
=
\sum_{i=1}^{M} w_i \mathcal{L}_{KD}^{(i)}.
\end{equation}
In the current launch script, \(\mathcal{L}_{KD}^{(i)}\) is the per-teacher
trie-Wasserstein loss. The selector is trained with a REINFORCE-style term
\begin{equation}
\mathcal{L}_{\mathrm{pol}}
=
-(r-b)\log p(\mathbf{m}\mid\boldsymbol{\pi}),
\end{equation}
where \(b\) is an EMA reward baseline. The current script uses
\(r=-\mathcal{L}_{CE}-\frac{1}{\sum_i m_i}\sum_i m_i\mathcal{L}_{KD}^{(i)}\),
so the total reinforced-selection objective is
\begin{equation}
\mathcal{L}_{\mathrm{RS}}
=
\mathcal{L}_{CE}
+ \gamma \mathcal{L}_{KD}
+ \lambda_{\pi}\mathcal{L}_{\mathrm{pol}}.
\end{equation}

Unless noted otherwise, all baselines reuse the same data conversion pipeline,
hardware, optimizer family and checkpointing protocol described earlier in
this chapter. Methods that do not use routing simply omit the GRACE-specific
terms and retain the corresponding single-teacher or uniform multi-teacher
objective from the cited source.
