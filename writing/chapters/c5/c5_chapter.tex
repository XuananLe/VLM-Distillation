\subsection{Overall Comparison}

Tables~\ref{tab:textvqa-comparison}, \ref{tab:docvqa-comparison} and \ref{tab:chartqa-comparison} summarize the main comparison results across original models, direct fine-tuning, standard logits distillation baselines and \methodname.

Unless stated otherwise, the main comparison tables report the strongest completed run for each method and benchmark. In particular, the adaptive heterogeneous multi-teacher rows, namely SHM-CKA, reinforced selection and \methodname{}, use the four-teacher pool \{Qwen2-VL-2B-Instruct, Qwen2.5-VL-3B-Instruct, InternVL3-1B, Gemma-3-4B-it\}. The Uniform baseline is reported from a cheaper two-teacher run with \{Qwen2-VL-2B-Instruct, Qwen2.5-VL-3B-Instruct\}. Chapter~\ref{chap:evaluation-methodology} documents the current three-teacher DocVQA launch script for systems and reproducibility details.

We report the baselines in four groups.

\begin{itemize}
\item The \textbf{non-distillation references} are the original student and the full-finetuning baseline.
\item The \textbf{same-family baselines} use \textbf{SmolVLM2-2.2B-Instruct} as teacher for forward KL, reverse KL and Jensen-Shannon divergence \cite{hinton2015distillingknowledgeneuralnetwork,xu2024surveyknowledgedistillationlarge,dasgupta2025improving}.
\item The \textbf{different-family single-teacher baselines}\\
use a teacher outside the SmolVLM family. This group includes the ULD baseline \cite{boizard2024towardscrosstokenizerdistillation}.
\item The \textbf{heterogeneous multi-teacher baselines} use teacher pools drawn from different VLM families, including uniform averaging, SHM-CKA, reinforced selection and \methodname{} \cite{williams1992simple,yuan2020reinforcedmultiteacherselection,zhang2023adaptivemultiteachermetalearning,yu2024selectdistill}.
\end{itemize}

We report each configuration as a single run. Multi-teacher training is
expensive in both GPU time and teacher-logit storage, so standard deviations are
not available for every method.

Because each multi-teacher run requires large offline logit caches and long
single-GPU training, we report one fully trained run per method. A typical H200
run takes about 7 hours, which is about 21 USD on Vast.ai before storage and
offline-logit generation cost. We therefore treat very small differences
cautiously, focus on consistent multi-point gaps across datasets and student
sizes and leave broader sweeps for later work.

The tables above show the end-point accuracy. The optimization path is also
different: \methodname{} is visibly more stable than static uniform averaging.

Several trends are consistent across the three benchmarks:
\begin{itemize}
    \item same-family logits baselines remain weak. Forward KL gives only small gains, reverse KL is consistently poor and Jensen-Shannon is unstable. Simply matching a same-family teacher distribution is not enough for these compact students.
    \item \textbf{cross-family ULD is already stronger than the same-family logits losses on all three tasks.} This shows that cross-tokenizer distillation is more useful here than vocabulary-matched KL. Once multiple heterogeneous teachers are added, uniform averaging gives another clear jump, which means teacher diversity itself is already valuable.
    \item \textbf{the remaining jump from the single-teacher ULD baseline to \methodname{} comes from the full recipe: a trie-Wasserstein KD loss, sample-dependent sparse routing and GRACE score refinement after routing.}
    \item \textbf{\methodname{} consistently improves on the uniform multi-teacher baseline for both student sizes.} The gain is moderate on TextVQA and DocVQA, but larger on ChartQA. This suggests that adaptive weighting helps most when the task mixes visual reading, numerical reasoning and teacher specialization.
\end{itemize}

\textbf{The gain is not just a small increment over a weak baseline.} On two
benchmarks, \methodname{} removes about half of the original teacher-student
gap. Even on DocVQA, where the teacher ceiling is highest, it still closes
almost 40\% of the gap.

\textbf{The student can even outperform some individual teachers in the pool.}
On TextVQA, \methodname{} reaches 69.38 and exceeds Gemma-3-4B-it at 57.80 by
+11.58 points (+20.03\%). On ChartQA, it exceeds InternVL3-1B at 75.30 by
+4.90 points (+6.51\%) and Gemma-3-4B-it at 63.60 by +16.60 points (+26.10\%).
This shows that the final student is not simply bounded by the weaker teachers
it learns from.

\textbf{One negative result is also consistent: reverse KL is much weaker than
forward KL.} This suggests that the more mode-seeking objective is a poor fit
for these compact multimodal students.

\textbf{SHM-CKA is not enough by itself.} SHM-CKA uses the same heterogeneous
teacher pool, but replaces routed weighting with hidden-state matching. It is
competitive on ChartQA, but clearly weaker on TextVQA and DocVQA. This implies
that representation alignment alone is not sufficient.
Teacher assignment matters, especially when the pool contains teachers with
different strengths and tokenizers.

\textbf{A clear limitation remains on the vision side.} The current method
distills supervised answer-token logits, pools student hidden states for
routing and scores teachers from CE/KD agreement at the output side. This is
effective, but it does not explicitly align visual features, cross-attention
patterns, or region-level evidence inside the VLM. The method therefore treats
the vision encoder mostly through its effect on the final answer distribution,
not as a first-class distillation target.

\section{Representation Similarity Analysis}

We use Centered Kernel Alignment (CKA) as an analysis tool to examine whether teacher and student layers
exhibit clear correspondence. For centered hidden-state matrices
\(\tilde{\mathbf{H}}_s\) and \(\tilde{\mathbf{H}}_t\), linear CKA is
\begin{equation}
\mathrm{CKA}(\tilde{\mathbf{H}}_s,\tilde{\mathbf{H}}_t)=
\frac{\left\|\tilde{\mathbf{H}}_t^{\top}\tilde{\mathbf{H}}_s\right\|_F^2}
{\left\|\tilde{\mathbf{H}}_t^{\top}\tilde{\mathbf{H}}_t\right\|_F
\left\|\tilde{\mathbf{H}}_s^{\top}\tilde{\mathbf{H}}_s\right\|_F}.
\end{equation}
Values closer to \(1\) indicate stronger representation similarity
\cite{kornblith2019similarityrepresentations}.

The main question is whether strong internal similarity is enough to justify
layer-wise distillation. Our results suggest that it is not, as shown in the
figures and tables below.

\section{Qualitative Analysis}
This section presents representative examples to inspect how distillation affects text reading and basic reasoning behavior.

\section{Discussion}
\begin{itemize}
    \item \textbf{The results show a clear ordering.} Same-family KL baselines are weakest, single cross-family distillation is stronger, uniform weighting improves again and \methodname{} is best overall \cite{hinton2015distillingknowledgeneuralnetwork,boizard2024towardscrosstokenizerdistillation}. This means that the problem is not solved by one trick alone. Heterogeneous teachers provide better supervision, but the student still needs a cross-tokenizer loss, sample-dependent routing and a stable post-routing weighting rule.
    \item the code-level implementation helps explain that pattern. The current training recipe uses a shared-trie Wasserstein loss for mismatched tokenizers, a routed multi-teacher setup with hard-routing warmup, top-\(k\) capacity control and GRACE score refinement with EMA-smoothed score updates \cite{boizard2024towardscrosstokenizerdistillation,peyre2019computationaloptimaltransport,fedus2022switchtransformersscalingtrillion}. The smoother training curve in Figure~\ref{fig:training-curve-comparison} is consistent with that design: the router narrows the teacher set first, then GRACE reweights only the routed teachers instead of averaging all teachers equally.
    \item the largest gain appears on ChartQA and the same trend also holds for the smaller 256M student. This suggests that sample-dependent teacher assignment is most useful when the task mixes visual parsing and numerical reasoning. It also shows that the method is not only helping the larger compact student. The improvement persists in the more resource-constrained regime.
    \item the comparison with SHM-CKA is also informative. SHM-CKA uses the same heterogeneous teacher pool, but it is less consistent than \methodname{}. Together with the CKA heatmaps, this suggests that internal similarity alone is not enough. \textbf{Good transfer still depends on which teacher is emphasized for each sample} \cite{kornblith2019similarityrepresentations,dasgupta2025improving}.
\end{itemize}

Two limitations remain:
\begin{itemize}
    \item the reported results are single-run numbers, because offline teacher-logit generation, remote storage and multi-teacher training are expensive. In our setup, a typical H200 run takes about 7 hours and costs about 21 USD on Vast.ai before cache-generation cost. This budget is the main reason some broader sweeps are still missing and are deferred to later work.
    \item the current implementation still depends on large remote teacher-logit caches. The method is effective, but the systems cost is still significant.
\end{itemize}
