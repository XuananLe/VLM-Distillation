\chapter{Experiment Results}
\label{chap:experiment-results}

This chapter reports the empirical results and analyzes what drives them. It
first compares GRACE with the baseline methods on the main benchmarks, then
examines stability, teacher usage and ablations. It closes with a discussion of
the main gains, limitations and remaining gaps.

\section{Main Comparison Results}
This section answers RQ1 from Chapter~\ref{chap:introduction} by comparing
\methodname{} with same-family logits KD, cross-tokenizer ULD and the
multi-teacher baselines on TextVQA, DocVQA and ChartQA.

\subsection{Overall Comparison}

Tables~\ref{tab:textvqa-comparison}, \ref{tab:docvqa-comparison} and \ref{tab:chartqa-comparison} summarize the main comparison results across original models, direct fine-tuning, standard logits distillation baselines and \methodname.

Unless stated otherwise, the main comparison tables report the strongest completed run for each method and benchmark. SHM-CKA, reinforced selection and \methodname{} use a four-teacher mixed set spanning the Qwen, InternVL and Gemma families. The Uniform baseline is reported from a cheaper two-teacher Qwen run. Chapter~\ref{chap:evaluation-methodology} documents the active three-teacher DocVQA launch script for systems and reproducibility details.

We report the baselines in four groups.

\begin{itemize}
\item The \textbf{non-distillation references} are the original student and the full-finetuning baseline used for comparison.
\item The \textbf{same-family baselines} use \textbf{SmolVLM2-2.2B-Instruct} as teacher for forward KL, reverse KL and Jensen-Shannon divergence \cite{hinton2015distillingknowledgeneuralnetwork,xu2024surveyknowledgedistillationlarge,dasgupta2025improving}.
\item The \textbf{different-family single-teacher baselines}\\
use a teacher outside the SmolVLM family. This group includes the ULD baseline \cite{boizard2024towardscrosstokenizerdistillation}.
\item The \textbf{multi-teacher baselines} compare a cheaper two-teacher Uniform average with four-teacher adaptive methods such as SHM-CKA, reinforced selection and \methodname{} \cite{williams1992simple,yuan2020reinforcedmultiteacherselection,zhang2023adaptivemultiteachermetalearning,yu2024selectdistill}.
\end{itemize}

We report each configuration as a single run. Multi-teacher training is
expensive in both GPU time and teacher-logit storage, so standard deviations are
not available for every compared method.

Because each multi-teacher run requires large offline logit caches and long
single-GPU training, we report one fully trained run per method. A typical H200
run takes about 7 hours, which is about 14.41 USD at 2.059 USD/hour on Vast.ai
before storage and offline-logit generation cost. We therefore treat very small differences
cautiously, focus on consistent multi-point gaps across datasets and student
sizes and leave broader sweeps for later work.

Several trends are consistent across the three benchmarks:
\begin{itemize}
    \item Same-family logits baselines remain weak. Forward KL gives only small gains, reverse KL is consistently poor and Jensen-Shannon is unstable. Simply matching a same-family teacher distribution is not enough for these compact students.
    \item \textbf{Cross-family ULD is already stronger than the same-family logits losses on all three tasks.} This shows that cross-tokenizer distillation is more useful here than vocabulary-matched KL. Once multiple teachers are added, Uniform averaging gives another clear jump, which means teacher diversity itself is already valuable.
    \item \textbf{The remaining jump from the single-teacher ULD baseline to \methodname{} comes from the full recipe: a trie-Wasserstein KD loss, sample-dependent sparse routing and GRACE score refinement after routing.}
    \item \textbf{\methodname{} consistently improves on the uniform multi-teacher baseline for both student sizes.} The gain is moderate on TextVQA and DocVQA, but larger on ChartQA. This suggests that adaptive weighting helps most when the task mixes visual reading, numerical reasoning and teacher specialization.
\end{itemize}

For the qualitative analysis below, we use DEX-AR
\cite{bousselham2026dexar}. For token \(t\), layer \(l\) and head \(h\),
DEX-AR forms a gradient-based attribution map
\[
\mathbf{G}_{t}^{(l,h)}
=
\nabla_{\mathbf{A}^{(l,h)}} y_t \odot \mathbf{A}^{(l,h)},
\]
then keeps visually grounded heads with
\[
w^{(l,h)}=\max\!\big(S_{\mathrm{img}}^{(l,h)}-S_{\mathrm{text}}^{(l,h)},0\big),
\]
and aggregates
\[
\mathbf{H}_t=\sum_{l,h} w^{(l,h)} \mathbf{G}_{t}^{(l,h)},
\qquad
\mathbf{H}_{\mathrm{sent}}=\sum_t \delta_t \mathbf{H}_t .
\]
Here \(\delta_t=1/|\Omega_{\mathrm{ans}}|\) for answer tokens
\(t\in\Omega_{\mathrm{ans}}\), so the sentence-level map is the uniform average
of token-level maps over the generated answer span.
We prefer DEX-AR over raw attention maps or generic saliency because the model
is autoregressive and the target is answer-token grounding, not generic image
saliency.

\begin{rqanswerbox}{Answer to RQ1}
\methodname{} consistently improves over direct finetuning and the compared
distillation baselines. The ranking is clear: same-family logits baselines are
weakest, cross-family ULD is stronger, multi-teacher baselines improve further
and \methodname{} is best overall. Within the multi-teacher group, static
Uniform averaging already helps, but \methodname{} stays ahead of SHM-CKA,
reinforced selection and Uniform itself. This shows that teacher diversity
already helps, but the largest gains come from combining the trie-Wasserstein
loss with gradient-based alignment. On SmolVLM-500M, \methodname{} closes
	\(39.53\%\) to \(55.34\%\) of the gap between the strongest teacher in the
	four-teacher comparison pool and the compact student.
\end{rqanswerbox}

\begin{itemize}
    \item \textbf{The gains over the original student are large:} +22.26\% on TextVQA, +22.83\% on DocVQA and +27.71\% on ChartQA. The gains over direct finetuning are almost as large: +21.80\%, +18.00\% and +27.30\%, respectively.

    \item \textbf{The pattern also holds for SmolVLM-256M.} \methodname{} rises from 47.17 to 60.73 on TextVQA (+28.75\%), from 48.64 to 60.48 on DocVQA (+24.34\%) and from 45.04 to 72.32 on ChartQA (+60.57\%).

The trend is similar if the reference point is the strongest teacher in the
\methodname{} comparison pool. This reference excludes the separate Granite
launch-path teacher reported in Table~\ref{tab:teacher-original-results}. Let
\(g_{\mathrm{orig}} = y_T - y_{\mathrm{orig}}\) and

\textbf{The student can even outperform some individual teachers in the pool.}
On TextVQA, \methodname{} reaches 69.38 and exceeds Gemma-3-4B-it at 57.80 by
+11.58 points (+20.03\%). On ChartQA, it exceeds InternVL3-1B at 75.30 by
+4.90 points (+6.51\%) and Gemma-3-4B-it at 63.60 by +16.60 points (+26.10\%).
This shows that the final student is not simply bounded by the weaker teachers
it learns from.

\textbf{One negative result is also consistent: reverse KL is much weaker than
forward KL.} This suggests that the more mode-seeking objective is a poor fit
for these compact multimodal students.

\textbf{SHM-CKA is not enough by itself.} SHM-CKA uses the heterogeneous
teacher set, but replaces routed weighting with hidden-state matching. It is
competitive on ChartQA, but clearly weaker on TextVQA and DocVQA. This implies
that representation alignment alone is not sufficient.
Teacher assignment matters, especially when the pool contains teachers with
different strengths and tokenizers.

\textbf{A clear limitation remains on the vision side.} The method
distills supervised answer-token logits, pools student hidden states for
routing and scores teachers from CE/KD agreement at the output side. This is
effective, but it does not explicitly align visual features, cross-attention
patterns, or region-level evidence inside the VLM. The method therefore treats
the vision encoder mostly through its effect on the final answer distribution,
not as a first-class distillation target.

\section{Representation Similarity Analysis}

We use Centered Kernel Alignment (CKA) as an analysis tool to examine whether teacher and student layers
exhibit clear correspondence. For centered hidden-state matrices
\(\tilde{\mathbf{H}}_s\) and \(\tilde{\mathbf{H}}_t\), linear CKA is
\begin{equation}
\mathrm{CKA}(\tilde{\mathbf{H}}_s,\tilde{\mathbf{H}}_t)=
\frac{\left\|\tilde{\mathbf{H}}_t^{\top}\tilde{\mathbf{H}}_s\right\|_F^2}
{\left\|\tilde{\mathbf{H}}_t^{\top}\tilde{\mathbf{H}}_t\right\|_F
\left\|\tilde{\mathbf{H}}_s^{\top}\tilde{\mathbf{H}}_s\right\|_F}.
\end{equation}
Values closer to \(1\) indicate stronger representation similarity
\cite{kornblith2019similarityrepresentations}.

The main question is whether strong internal similarity is enough to justify
layer-wise distillation. Our results suggest that it is not, as shown in the
figures and tables below.

\section{Ablation Study}
This section answers RQ2 from Chapter~\ref{chap:introduction} by isolating the
main components of \methodname{} on DocVQA. Table~\ref{tab:docvqa-planned-ablation}
keeps the teacher set and KD loss close to the final method and changes one
mechanism at a time:
\begin{itemize}
\item \textbf{Cross-family ULD (single teacher)} uses one cross-family teacher and optimizes \(\mathcal{L}=\mathcal{L}_{CE}+\alpha\mathcal{L}_{ULD}\), with \(\mathcal{L}_{ULD}=\|\pi(p_s)-\pi(p_t)\|_1\). This provides the single-teacher cross-tokenizer baseline.
\item \textbf{Uniform multi-teacher} averages the active per-teacher KD losses, \(\mathcal{L}=\mathcal{L}_{CE}+\alpha \frac{1}{M}\sum_{i=1}^{M}\mathcal{L}_{TW}^{(i)}\). This tests whether teacher diversity alone explains the gain.
\item \textbf{Routing only + trie-Wasserstein} keeps sparse routing but disables GRACE refinement after routing, so \(w_i^{(b)}=u_i^{(b)}=\mathbf{1}[i\in\mathcal{R}_b]/|\mathcal{R}_b|\). This tests whether routing alone explains the gain.
\item \textbf{Full GRACE + trie-Wasserstein} is the full method and serves as the reference row, with \(w_i^{(b)}\propto (\hat p_i^{(b)})^{\lambda_{\mathrm{blend}}}(\omega_i^{(b)})^{1-\lambda_{\mathrm{blend}}}\).
\item \textbf{Full GRACE + trie-Wasserstein (\(\lambda_{\mathrm{blend}} = 1.0\))} reduces the final weights to router weights only, \(w_i^{(b)}=\hat p_i^{(b)}\) after normalization over routed teachers. This tests whether post-routing blending matters.
\item \textbf{Full GRACE + trie-Wasserstein (\(\beta_{\mathrm{EMA}}=0\))} removes EMA smoothing, so \(\hat{s}_i=s_i\) and \(\omega_i^{(b)}=\mathrm{Softmax}(\beta_{\mathrm{score}}s_i)\) over the active routed set. This tests whether temporal score smoothing stabilizes teacher weighting.
\end{itemize}

Table~\ref{tab:docvqa-planned-ablation} shows that the full variant remains the
strongest setting for both student sizes. Relative to routing only, it gains
3.03 points on SmolVLM-256M and 9.88 points on SmolVLM-500M, which indicates
that sparse routing alone does not explain the final improvement.

The table also reveals two distinct post-routing gains. On SmolVLM-500M,
moving from routing-only weights to router-only weights
(\(\lambda_{\mathrm{blend}}=1.0\))
already adds 7.22 points (63.23 \(\rightarrow\) 70.45) and full GRACE adds
another 2.66 points (70.45 \(\rightarrow\) 73.11). On SmolVLM-256M, the
router-only gain is only 0.52 points (57.45 \(\rightarrow\) 57.97), while
gradient-based refinement adds 2.51 points (57.97 \(\rightarrow\) 60.48). This
suggests that the gate provides a coarse ranking, especially for the larger
student, whereas gradient-based reweighting is the more universal corrective
layer \cite{zhu2021studentcustomized,yuan2020reinforcedmultiteacherselection}.
This also suggests an interaction between student size and routing quality: the
larger student appears to extract stronger routing features from its hidden
states, while the smaller student relies more on the GRACE refiner. This is an
inference from the ablation pattern, not a direct causal proof.

Removing EMA smoothing causes smaller but consistent degradations, suggesting
that temporal score smoothing stabilizes teacher weighting instead of replacing
the main contribution of GRACE-guided blending.

\begin{rqanswerbox}{Answer to RQ2}
GRACE works because it combines a strong cross-tokenizer KD loss
(trie-Wasserstein), sample-dependent sparse routing and, most critically,
post-routing gradient-based score refinement. EMA smoothing is a supportive
stabilizer, while the entropy and \(z\)-loss terms regularize the router.
\end{rqanswerbox}

\section{Efficiency Analysis}
This section addresses RQ3 from Chapter~\ref{chap:introduction}. Runtime,
training cost and storage overhead will be summarized here.

\begin{rqanswerbox}{Answer to RQ3}
The cost of \methodname{} is dominated by GPU training rather than object
storage. From the Vast.ai screenshot, one H200 instance costs 2.059 USD/hour,
so a 7-hour run costs about \(7\times2.059=14.41\) USD and a 2500 USD budget
corresponds to
\[
\frac{2500}{2.059} \approx 1214.18 \text{ GPU-hours},
\]
which is about 50.59 days of continuous single-GPU runtime. If one full run
takes about 7 hours, this budget is equivalent to roughly
\[
\frac{1214.18}{7} \approx 173
\]
single-H200 runs.

The storage side is much cheaper under the official Cloudflare R2 standard
pricing policy: 0.015 USD/GB-month for storage, 4.50 USD per million Class A
operations, 0.36 USD per million Class B operations and zero egress. Using the
dashboard values in Figure~\ref{fig:r2-storage}, 1.04 TB of stored logits is
about 1040 GB, which gives
\[
1040 \times 0.015 = 15.60 \text{ USD/month}.
\]
The 598.73k Class A operations stay below the 1M monthly free allowance, so
their marginal cost is 0 USD. The 20.3M Class B operations exceed the 10M free
allowance by 10.3M, which gives
\[
10.3 \times 0.36 = 3.71 \text{ USD}.
\]
The total R2 cost is therefore about
\[
15.60 + 3.71 = 19.31 \text{ USD/month},
\]
before billing-unit rounding. This is below 1\% of the 2500 USD GPU budget,
which means the main efficiency bottleneck is training compute and offline
logit generation, not storage egress or serving cost.
\end{rqanswerbox}

\section{Discussion}
\begin{itemize}
    \item \textbf{The results show a clear ordering.} Same-family KL baselines are weakest, single cross-family distillation is stronger, uniform weighting improves again and \methodname{} is best overall \cite{hinton2015distillingknowledgeneuralnetwork,boizard2024towardscrosstokenizerdistillation}. This means that the problem is not solved by one trick alone. Heterogeneous teachers provide better supervision, but the student still needs a cross-tokenizer loss, sample-dependent routing and a stable post-routing weighting scheme.
    \item The code-level implementation helps explain that pattern. The training recipe uses a shared-trie Wasserstein loss for mismatched tokenizers, a routed multi-teacher setup with top-\(k\) masking, routed-weight renormalization and GRACE score refinement with EMA-smoothed score updates \cite{boizard2024towardscrosstokenizerdistillation,peyre2019computationaloptimaltransport,fedus2022switchtransformersscalingtrillion}. The smoother training curve in Figure~\ref{fig:training-curve-comparison} is consistent with that design: the router narrows the teacher set first, then GRACE reweights only the routed teachers instead of averaging them uniformly.
    \item The largest gain appears on ChartQA and the trend also holds for the smaller 256M student. This suggests that sample-dependent teacher assignment is most useful when the task mixes visual parsing and numerical reasoning. It also shows that the method is not only helping the larger compact student. The improvement persists in the more resource-constrained regime.
    \item The comparison with SHM-CKA is also informative. SHM-CKA uses the heterogeneous teacher set, but it is less consistent than \methodname{}. Together with the CKA heatmaps, this suggests that internal similarity alone is not enough. \textbf{Good transfer still depends on which teacher is emphasized for each sample} \cite{kornblith2019similarityrepresentations,dasgupta2025improving}.
\end{itemize}

\section{Limitations and Threats to Validity}
\begin{itemize}
    \item \textbf{Cost-limited evaluation.} The reported numbers are single-run results. A typical H200 run takes about 7 hours and costs about 14.41 USD at 2.059 USD/hour on Vast.ai before offline cache-generation and storage cost. This limits repeated seeds, confidence intervals and broader hyperparameter sweeps, so small gaps between strong baselines should be interpreted cautiously.
    \item \textbf{Incomplete apples-to-apples coverage across all baselines.} The strongest adaptive rows use the full heterogeneous teacher set, while the Uniform baseline is reported from a cheaper two-teacher run. The active Chapter~\ref{chap:evaluation-methodology} launch path also documents one three-teacher DocVQA recipe, whereas the main result tables aggregate broader completed runs. This does not invalidate the overall trend, but it weakens strict per-row comparability.
    \item \textbf{Answer-token-centric transfer.} The method distills teacher distributions on supervised answer positions, routes teachers from pooled student states and refines them with CE/KD gradient agreement. It does not explicitly align visual tokens, cross-attention maps or region-level evidence. As a result, some gains may come mainly from output-side transfer instead of deeper visual grounding.
    \item \textbf{Systems dependence.} The implementation relies on large offline teacher-logit caches, remote object storage and local streaming caches. This keeps the online loop simple, but it raises storage, I/O and reproducibility requirements. The method is therefore easier to reproduce in a well-provisioned training environment than on minimal local hardware.
    \item \textbf{Scope of validation.} The empirical study focuses on text-rich VQA benchmarks and compact students in the SmolVLM family. The reported gains are strong in this regime, but the thesis does not yet establish the same behavior for other multimodal task families, other student architectures or larger teacher pools.
\end{itemize}
