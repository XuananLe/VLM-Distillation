\chapter{Proposed Method}
\label{chap:proposed-method}

GRACE addresses three constraints that existing methods handle separately:
vocabulary mismatch between teacher and student, variable teacher usefulness
across samples, and KD gradients that conflict with the supervised CE
objective. Each component of the framework resolves the limitation the
previous one leaves open.

\section{Method Overview and Problem Formulation}
\label{sec:method-overview-formulation}

We consider a training set
\[
\mathcal{D}=\{(x_n,y_n)\}_{n=1}^{N_{\mathrm{data}}},
\]
where \(x_n\) is a multimodal input and \(y_n\) is the target answer sequence.


Let \(S_{\theta}\) denote the student VLM with trainable parameters
\(\theta\), let \(G_{\phi}\) denote the trainable teacher router with
parameters \(\phi\) and let \(\mathcal{T}=\{T_i\}_{i=1}^{N}\) be the frozen
teacher pool. For each sample \(b\), the student produces logits
\(\mathbf{z}_s^{(b)}\) and teacher \(T_i\) provides logits
\(\mathbf{z}_t^{(b,i)}\).

Three constraints shape the GRACE design. First, teacher and student output spaces use different token
indices, so the KD loss compares decoded token content through a shared
string space. Second, teacher usefulness is sample-dependent: a
teacher that is useful for document layout may be less useful for chart
reasoning or natural scene text. Third, teacher relevance and optimization
compatibility can diverge when a teacher's logits look correct but its gradient conflicts with the CE objective. GRACE addresses these constraints with \textbf{Byte-Trie Wasserstein}
matching, \textbf{sparse teacher routing} and \textbf{gradient-agreement
refinement}.

Figure~\ref{fig:grace-architecture} summarizes the full training pipeline.
The router uses pooled student hidden states to select a sparse teacher subset;
Byte-Trie Wasserstein KD then computes a per-teacher loss by matching decoded
token paths through a shared byte trie. Gradient-agreement refinement adjusts
the selected teacher weights by how well each teacher's KD gradient aligns
with the supervised CE objective. The final objective combines supervised
cross-entropy, this routed KD signal and two router regularization terms
\cite{shazeer2017outrageouslylargeneuralnetworks,fedus2022switchtransformersscalingtrillion,zhu2021studentcustomized}.

A GRACE update starts from a mini-batch
\[
\mathcal{B}=\{(x_b,y_b)\}_{b=1}^{B}
\]
and the frozen teacher pool \(\mathcal{T}\). The student first
produces logits, hidden states and the supervised cross-entropy loss for the answer tokens. The
router then uses the pooled student hidden state to select a sparse routed set
\(\mathcal{R}_b\) for each sample. For every selected teacher, Byte-Trie Wasserstein
KD computes a per-teacher loss \(\mathcal{L}_{KD}^{(b,i)}\), using the shared
byte-trie geometry to compare student and teacher output distributions.
Gradient-agreement refinement then adjusts routed teacher weights by
comparing each teacher's KD gradient with the supervised CE gradient. The routed KD signal for sample \(b\)
is the weighted combination of teacher-specific losses:
\[
\bar{\mathcal{L}}_{KD}^{(b)}
=
\sum_{i\in\mathcal{R}_b}
w_i^{(b)}\mathcal{L}_{KD}^{(b,i)}.
\]
The final weights \(w_i^{(b)}\) are determined by both the router and the
gradient-agreement refinement step. The method introduces several hyperparameters
(\(\rho_{\mathrm{trie}}\), \(\eta_{\mathrm{boundary}}\), \(K_{\mathrm{TW}}\),
\(k_{\mathrm{route}}\), \(\beta_{\mathrm{EMA}}\), \(\lambda_{\mathrm{blend}}\)
and others); their values and the ablation study that isolates the most
influential ones are reported in Appendix~\ref{app:experiment-parameters} and
Section~\ref{sec:ablation} respectively. The main notation
used throughout the method is listed in Table~\ref{tab:notation}.

\section{Byte-Trie Wasserstein Distillation}
\label{sec:byte-trie-wasserstein-distillation}

For sample \(b\) and teacher \(T_i\), GRACE restricts KD to matched answer
positions \(\Omega_{b,i}^{KD}\), after masking ignored labels and truncating
student and teacher answer spans to a common length. At each position
\(j \in \Omega_{b,i}^{KD}\), the student and teacher logits define softened
distributions
\[
p^{(b)}_{s,j}
=
\mathrm{softmax}\!\left(z^{(b)}_{s,j}/\tau_s\right),
\qquad
p^{(b,i)}_{t,j}
=
\mathrm{softmax}\!\left(z^{(b,i)}_{t,j}/\tau_t\right).
\]
The remaining computation has three steps: map decoded tokens into a shared
byte trie, approximate the full vocabulary distributions with sparse retained
supports and residual tail mass, and compute the tree-Wasserstein loss from
subtree-mass imbalances.

\subsection{Shared Byte Trie}

Applying KD by token index requires aligned vocabularies, but with different
tokenizers the same index may correspond to unrelated decoded strings. GRACE therefore maps decoded teacher and student tokens into a shared UTF-8
byte trie. Each token's boundary markers are separated from its lexical
content; the content is normalized and encoded as bytes, then terminated with
an EOS sentinel so that complete tokens remain distinct from strict prefixes.

This canonicalization suppresses tokenizer artifacts during trie-based matching. Many tokenizers encode word boundaries with visible markers
or leading whitespace, even when the underlying answer string is the same.
GRACE separates this boundary information from the byte path of the token content. The
normalized content determines the main trie path, while boundary markers are
represented by optional low-cost boundary edges. Tokens sharing lexical content therefore land close in the trie, while the
low-weight boundary edges still penalize whitespace differences when present.

A document-style answer string such as ``invoice'', in the DocVQA setting
\cite{mathew2021docvqadatasetvqadocument}, illustrates the problem.
A tokenizer with an explicit word-boundary marker may produce it as a single
token \texttt{<wb>invoice}, where \texttt{<wb>} marks the word boundary, while
another tokenizer splits it into \texttt{in} and \texttt{voice}. Without canonicalization,
\texttt{<wb>invoice} and \texttt{in} share no index and the loss cannot relate
them. After canonicalization, the boundary marker is stripped from the main
path and placed on a low-cost boundary edge; the byte sequence
\texttt{invoice} is inserted into the trie, where \texttt{in} already occupies
the same prefix. Transport between \texttt{<wb>invoice} and \texttt{in} is
therefore low, reflecting the genuine lexical overlap rather than an index
coincidence.

Appending an EOS sentinel prevents prefix collapse by creating distinct
terminal paths, so \texttt{doc} is distinguishable from the prefix of \texttt{document}.

The trie defines the ground-cost geometry for token comparison. Content and EOS
edges receive weights that decay with depth, while optional boundary edges receive a
small fixed weight:
\begin{equation}
w(e)=
\begin{cases}
\rho_{\mathrm{trie}}^{d(e)-1}, & e \in E_{\mathrm{content}}\cup E_{\mathrm{EOS}},\\
\eta_{\mathrm{boundary}}, & e \in E_{\mathrm{boundary}}.
\end{cases}
\label{eq:tw_edge_weight}
\end{equation}
where \(0<\rho_{\mathrm{trie}}<1\), \(\eta_{\mathrm{boundary}}\ge 0\) and
\(d(e)\) is the edge depth. Thus, tokens sharing long byte prefixes receive
low transport cost under the trie metric even if they come from different tokenizers
\cite{takezawa2021supervisedtreewasserstein,peyre2019computationaloptimaltransport}.

\subsection{Sparse Support and Residual Tail Edge}

Using the complete vocabulary trie at every answer position is computationally
prohibitive, scaling with the number of vocabulary entries per position.
GRACE therefore keeps only the top-\(K_{\mathrm{TW}}\) student and teacher
tokens after masking ignored entries. The retained tokens are inserted along
their canonical trie paths, while all omitted probability mass is collapsed into
a residual tail edge \(e_{\mathrm{tail}}\). This preserves total probability
mass while keeping the active edge set small.

Let \(K_{\mathrm{TW}}\) denote the sparse trie support size. Let
\(\mathcal{V}_s^\star\) and \(\mathcal{V}_t^\star\) denote the non-ignored
student and teacher vocabularies. Before constructing the sparse trie, the
student and teacher probabilities are renormalized over the non-ignored
vocabularies so that the retained and residual masses form valid
distributions. Ignored entries are excluded from the softmax normalizer before
top-\(K_{\mathrm{TW}}\) selection.
Let
\(\mathcal{K}_{s,j}^{(b)}\subset\mathcal{V}_s^\star\) and
\(\mathcal{K}_{t,j}^{(b,i)}\subset\mathcal{V}_t^\star\) be the retained token
sets. The residual mass assigned to the tail edge is
\begin{equation}
r_{s,j}^{(b)}
=
1-\sum_{v\in\mathcal{K}_{s,j}^{(b)}}p_{s,j}^{(b)}(v),
\qquad
r_{t,j}^{(b,i)}
=
1-\sum_{v\in\mathcal{K}_{t,j}^{(b,i)}}p_{t,j}^{(b,i)}(v).
\end{equation}
The residual tail preserves probability mass outside the retained
top-\(K_{\mathrm{TW}}\) support. For the student distribution,
\[
\sum_{v\in\mathcal{K}_{s,j}^{(b)}}p_{s,j}^{(b)}(v)
+ r_{s,j}^{(b)} = 1,
\]
and the same identity holds for the teacher. The retained top-\(K_{\mathrm{TW}}\) paths are compared explicitly while the
rest of the probability mass is pooled into the shared tail.
When teacher distributions are softened, non-trivial probability mass can lie outside the top answer token.

Let \(\pi(v)\) be the trie path for token \(v\), including canonical content
edges, the EOS edge and any optional boundary edge. Let
\(e_{\mathrm{tail}}\) be the global residual tail edge with
\(w(e_{\mathrm{tail}})=1\). For any active trie edge \(e\), the sparse subtree
masses are
\begin{equation}
m_{s,j}^{(b)}(e)
=
\sum_{\substack{v\in\mathcal{K}_{s,j}^{(b)}\\e\in\pi(v)}}
p_{s,j}^{(b)}(v)
+
\mathbf{1}[e=e_{\mathrm{tail}}]\,r_{s,j}^{(b)},
\end{equation}
\begin{equation}
m_{t,j}^{(b,i)}(e)
=
\sum_{\substack{v\in\mathcal{K}_{t,j}^{(b,i)}\\e\in\pi(v)}}
p_{t,j}^{(b,i)}(v)
+
\mathbf{1}[e=e_{\mathrm{tail}}]\,r_{t,j}^{(b,i)}.
\end{equation}

\subsection{Byte-Trie Wasserstein Objective}

Given the shared trie, each distribution induces subtree masses on active
edges. In the dense form, let \(\mathcal{V}_s\) and \(\mathcal{V}_t\) denote
the student and teacher token vocabularies at a given answer position. For edge
\(e\), \(m_s(e)\) and \(m_t(e)\) measure how much student and teacher
probability passes through that edge:
\[
m_s(e)
=
\sum_{\substack{v\in\mathcal{V}_s\\ e\in\pi(v)}} p_s(v),
\qquad
m_t(e)
=
\sum_{\substack{u\in\mathcal{V}_t\\ e\in\pi(u)}} p_t(u).
\]
On a tree metric, the Wasserstein distance has the closed form
\begin{equation}
W_T(p_s,p_t)
=
\sum_{e\in E}
w(e)\left|m_s(e)-m_t(e)\right|.
\label{eq:trie-wasserstein-objective}
\end{equation}
This form follows from the standard \(W_1\) Kantorovich optimal transport
problem under the trie-induced tree metric
\cite{peyre2019computationaloptimaltransport,takezawa2021supervisedtreewasserstein}.
The full proof is provided in Appendix~\ref{app:tree-wasserstein-proof}. In
training, GRACE evaluates the same per-edge formula on the sparse active edge
set defined above, using the retained token paths and residual tail edge.
The token-level Byte-Trie Wasserstein loss is
\begin{equation}
\ell_{TW}\!\left(\mathbf{z}_{s,j}^{(b)},\mathbf{z}_{t,j}^{(b,i)}\right)
=
\sum_{e\in\mathcal{E}_{act,j}^{(b,i)}}
w(e)\,
\left|
m_{s,j}^{(b)}(e)-m_{t,j}^{(b,i)}(e)
\right|,
\label{eq:token_tw}
\end{equation}
where \(\mathcal{E}_{act,j}^{(b,i)}\) contains the active canonical content
edges, EOS edges, optional boundary edges and the residual tail edge from the
student and teacher supports.

The per-sample, per-teacher KD loss is the mean over supervised answer
tokens:
\begin{equation}
\mathcal{L}_{KD}^{(b,i)}
=
\frac{1}{|\Omega_{b,i}^{KD}|}
\sum_{j\in\Omega_{b,i}^{KD}}
\ell_{TW}\!\left(\mathbf{z}_{s,j}^{(b)},\mathbf{z}_{t,j}^{(b,i)}\right).
\label{eq:per_teacher_tw}
\end{equation}

The Byte-Trie Wasserstein loss performs exact transport under the trie metric.
The complexity analysis below describes the cost of evaluating this sparse
per-edge formula during training.

\textbf{Complexity Analysis.}
The shared byte trie is built once with cost
\(O(V_s\bar{L}_s + V_t\bar{L}_t)\), where \(V_s,V_t\) are the student and
teacher vocabulary sizes and \(\bar{L}_s,\bar{L}_t\) are average trie-path
lengths. During training, each aligned answer position keeps only the
top-\(K_{\mathrm{TW}}\) student and teacher tokens and accumulates probability
mass along their active trie paths. The per-position cost is
\[
O\!\left((V_s+V_t)\log K_{\mathrm{TW}}
+ K_{\mathrm{TW}}(\bar{L}_s+\bar{L}_t) + A\right),
\]
where \(A\) is the number of active trie edges. Thus, sparse Byte-Trie Wasserstein
matching avoids materializing the dense \(|V_s|\times |V_t|\) optimal-transport
matrix.


\section{Teacher Routing Network}
\label{sec:teacher-routing-network}

Uniform teacher averaging ignores how each teacher performs across different samples. GRACE therefore uses a student-conditioned router to propose a small teacher
set for each sample before gradient-agreement refinement adjusts their weights. The full pipeline
from pooled student features to sparse top-\(k\) teacher selection is shown in
Figure~\ref{fig:deep-router}
\cite{shazeer2017outrageouslylargeneuralnetworks,fedus2022switchtransformersscalingtrillion,yuan2020reinforcedmultiteacherselection}.

\begin{figure}
\centering
\includegraphics[width=\linewidth]{figures/deep-router.pdf}
\caption{Teacher routing network.}
\label{fig:deep-router}
\end{figure}

Let \(\mathbf{H}_s^{(b)}\) be the student hidden states before the language-model
head. GRACE pools the supervised answer positions to obtain the routing feature
\[
\mathbf{h}^{(b)}=\mathrm{Pool}(\mathbf{H}_s^{(b)}).
\]
Answer-position pooling restricts the routing feature to the supervised span
of the sequence, so the router sees a representation in which visual context,
question text and answer states have already interacted. Teacher usefulness
depends on the answer span being generated, not only on the input type.

A learned MLP router \(G_{\phi}(\cdot)\) maps this feature to teacher logits
and soft weights:
\[
\mathbf{r}^{(b)}=G_{\phi}(\mathbf{h}^{(b)}),
\qquad
\mathbf{p}^{(b)}=\mathrm{softmax}(\mathbf{r}^{(b)}).
\]
The router then keeps the top-\(k_{\mathrm{route}}\) teachers:
\[
\mathcal{R}_b=\mathrm{TopK}(\mathbf{r}^{(b)},\min(k_{\mathrm{route}},N)).
\]
Non-selected weights are zeroed and the selected weights are renormalized:
\begin{equation}
\hat{p}_i^{(b)}
=
\frac{\mathbf{1}[i\in\mathcal{R}_b] p_i^{(b)}}
{\sum_{j=1}^{N}\mathbf{1}[j\in\mathcal{R}_b] p_j^{(b)}}.
\label{eq:constrained_gate_weights}
\end{equation}
The router determines which frozen teachers contribute to each student update
without modifying the student architecture. Because \(\mathbf{h}^{(b)}\)
reflects the current student hidden states, the routed set \(\mathcal{R}_b\)
changes as the student evolves, so teacher selection adapts to both input
content and the current student state.

Top-\(k\) routing has two roles. First, it makes the teacher mixture sparse:
only \(k_{\mathrm{route}}\) teacher losses can enter routed KD regardless of
pool size. Second, it separates candidate selection from final weighting. The
router proposes a candidate teacher set; Section~\ref{sec:gradient-agreement}
then describes how gradient agreement refines their weights. Router probability
captures input-level relevance; gradient agreement checks whether the selected
KD gradients support the supervised objective.

Figure~\ref{fig:grace-routing-dynamics} contrasts dense teacher probabilities
with the sparse routed assignment.

\begin{figure}
    \centering
    \includegraphics[width=0.78\linewidth]{figures/grace_routing_dynamics.png}
    \caption[Top-\(k\) routing dynamics.]{Top-\(k\) routing dynamics.}
    \label{fig:grace-routing-dynamics}
\end{figure}

Two auxiliary terms regularize teacher selection. The entropy term is a negative-entropy regularizer that discourages premature
routing collapse
\cite{shazeer2017outrageouslylargeneuralnetworks,fedus2022switchtransformersscalingtrillion}:
\begin{equation}
\mathcal{L}_{ent}
=
-\frac{1}{B}\sum_{b=1}^{B} H(\mathbf{p}^{(b)}).
\end{equation}
The \(z\)-loss penalizes large router logit magnitudes:
\begin{equation}
\mathcal{L}_{z}
=
\frac{1}{B}\sum_{b=1}^{B}
\left(\log \sum_{i=1}^{N} e^{r_i^{(b)}}\right)^2.
\end{equation}
The two terms serve different purposes. The entropy term discourages the
router from assigning all samples to one teacher early in training, while the
\(z\)-loss limits excessively sharp routing logits. These auxiliary losses
stabilize teacher selection; CE and routed KD remain the main training signals.

\section{Gradient-Agreement Refinement}
\label{sec:gradient-agreement}
\label{sec:gradient-agreement-refinement}

Routing proposes teachers relevant to each sample, but a selected teacher may still
produce a KD gradient that conflicts with the supervised CE objective. GRACE computes one agreement score per teacher per mini-batch and uses it to
reweight each sample's routed teachers.

\subsection{Agreement Score Computation}
\label{sec:agreement-score-computation}

Let \(\mathbf{g}_{CE}=\nabla_{\Theta}\mathcal{L}_{CE}\) be the supervised
gradient over trainable student parameters \(\Theta\). For teacher \(T_i\),
GRACE first averages its KD loss over the mini-batch and then computes
\[
\mathbf{g}_{i}
=
\nabla_{\Theta}
\left(
\frac{1}{B}\sum_{b=1}^{B}
\mathcal{L}_{KD}^{(b,i)}\right),
\]
where \(\mathcal{L}_{KD}^{(b,i)}\) is the Byte-Trie Wasserstein loss from
Equation~\ref{eq:per_teacher_tw}. The raw agreement score is the cosine
similarity
\begin{equation}
s_i
=
\frac{
\langle \mathbf{g}_{CE},\mathbf{g}_i\rangle
}{
\max\!\left(\|\mathbf{g}_{CE}\|_2\|\mathbf{g}_i\|_2,\epsilon_{\mathrm{num}}\right)
}.
\label{eq:grace-gradient-agreement-score}
\end{equation}
Cosine similarity is appropriate here because both the KD and CE losses
optimize the same student parameters; it also normalizes for gradient magnitude,
making the score independent of teacher-to-teacher scale differences.
Consider one gradient step with routed KD:
\[
\Delta\theta
=
-\eta
\left(
\mathbf{g}_{CE}
+
\alpha_{\mathrm{KD}}\sum_i w_i \mathbf{g}_i
\right).
\]
The first-order change in the supervised CE loss is
\[
\Delta\mathcal{L}_{CE}
\approx
\mathbf{g}_{CE}^{\top}\Delta\theta
=
-\eta\|\mathbf{g}_{CE}\|_2^2
-
\eta\alpha_{\mathrm{KD}}\sum_i w_i
\langle \mathbf{g}_{CE},\mathbf{g}_i\rangle .
\]
When \(\langle \mathbf{g}_{CE},\mathbf{g}_i\rangle>0\), teacher \(T_i\)'s KD
direction supports the supervised CE update. When the inner product is
negative, the teacher pushes against the supervised CE objective. GRACE weights each routed teacher's contribution by gradient agreement
\cite{yu2020gradient}.

The score \(s_i\) is batch-level, computed once per teacher, but produces
per-sample variation through its intersection with each sample's routed set
\(\mathcal{R}_b\).

\subsection{Warmup, EMA Smoothing and Active Set}
\label{sec:agreement-smoothing-active-set}

GRACE converts raw agreement scores into final weights in four steps.
During warmup (the first \(\rho_g T_{\mathrm{train}}\) steps), routed weights
pass through unchanged: \(w_i^{(b)}=\hat{p}_i^{(b)}\). Skipping agreement
scoring early in training reflects a stability choice: before the router has
seen enough data, agreement scores computed from an unstable student are too
noisy to filter reliably. After warmup, the steps
are as follows. First, the raw score is thresholded:
\[
\tilde{a}_i=\mathbf{1}[s_i>\delta].
\]
Second, it is smoothed with EMA:
\[
\hat{s}_i
=
\beta_{\mathrm{EMA}}\hat{s}^{\mathrm{prev}}_i
+
(1-\beta_{\mathrm{EMA}})s_i.
\]
A noisy batch agreement score fluctuates across training steps; EMA dampens
this before softmax weighting, as Figure~\ref{fig:grace-ema-smoothing} shows.

The raw score and smoothed score serve different purposes: \(s_i\) thresholds
by current-batch agreement, while \(\hat{s}_i\) weights teachers to smooth out
per-batch noise.

\begin{figure}[!htbp]
    \centering
    \includegraphics[width=0.96\linewidth]{figures/grace_ema_smoothing.png}
    \caption[EMA smoothing.]{EMA smoothing.}
    \label{fig:grace-ema-smoothing}
\end{figure}

Third, the active set for sample \(b\) is formed by intersecting the threshold
flag \(\tilde{a}_i\) with the routed set:
\begin{equation}
\mathcal{A}_b=\{i\in\mathcal{R}_b:\tilde{a}_i=1\}.
\label{eq:grace-sample-active-set}
\end{equation}
Fourth, the smoothed scores are passed through a softmax over \(\mathcal{A}_b\)
to produce agreement weights \(\omega\):
\begin{equation}
\omega_i^{(b)}
=
\frac{
\exp(\beta_{\mathrm{score}}\hat{s}_i) \mathbf{1}[i \in \mathcal{A}_b]
}{
\sum_{j=1}^{N}
\exp(\beta_{\mathrm{score}}\hat{s}_j) \mathbf{1}[j \in \mathcal{A}_b]
},
\label{eq:grace_softmax}
\end{equation}

\subsection{Fallback, Uniform and Blended Weighting}
\label{sec:agreement-weighting-rule}

The final rule, summarized in Figure~\ref{fig:grace-score-refinement}, chooses
among three cases. If \(\mathcal{A}_b\) is empty, GRACE falls back to the
routed weights \(\hat{p}^{(b)}\). If the score spread inside \(\mathcal{A}_b\)
is below \(\epsilon_{\mathrm{fb}}\) (scores nearly tied), GRACE uses uniform
weights over \(\mathcal{A}_b\).
Otherwise, it geometrically blends the routed weights \(\hat{p}\) and the
agreement weights \(\omega\):
\begin{equation}
w_i^{(b)}
=
\frac{(\hat{p}_i^{(b)})^{\lambda_{\mathrm{blend}}}
(\omega_i^{(b)})^{1-\lambda_{\mathrm{blend}}}
\,\mathbf{1}[i\in\mathcal{A}_b]}
{\sum_{j=1}^{N}(\hat{p}_j^{(b)})^{\lambda_{\mathrm{blend}}}
(\omega_j^{(b)})^{1-\lambda_{\mathrm{blend}}}
\,\mathbf{1}[j\in\mathcal{A}_b]}.
\label{eq:effective_teacher_weights}
\end{equation}
Here, \(\lambda_{\mathrm{blend}}\in[0,1]\) interpolates between pure score
weighting and pure router weighting.

    \centering
    \includegraphics[width=\linewidth]{figures/grace_score_refinement.png}
    \caption[GRACE score refinement.]{GRACE score refinement.}
    \label{fig:grace-score-refinement}
\end{figure}

Figure~\ref{fig:grace-weighting-cases} illustrates these three weighting
outcomes after routing. When one active teacher is strongly preferred, the final weight shifts toward
it. If the router and gradient agreement favor different teachers, the
geometric blend preserves contributions from both. If active teacher scores are
nearly equal, GRACE treats them as indistinguishable and uses uniform weights
over the active set.

Gradient-agreement refinement restricts the final mixture to the routed set
\(\mathcal{R}_b\), so the final routed KD term contains at most
\(k_{\mathrm{route}}\) nonzero teachers per sample. The per-teacher losses are computed before GRACE weights are applied, so the
weighting step has access to all \(\mathcal{L}_{KD}^{(b,i)}\) values.

\section{Routed KD Aggregation and Final Objective}
\label{sec:routed-kd-final-objective}

At the sample level, only teachers in the routed set $\mathcal{R}_b$ contribute
to the KD loss:
\begin{equation}
\bar{\mathcal{L}}_{KD}^{(b)}
=
\sum_{i\in\mathcal{R}_b} w_i^{(b)}\mathcal{L}_{KD}^{(b,i)},
\label{eq:sample-kd}
\end{equation}
where $w_i^{(b)}$ reflects whichever of the three weighting rules applies
(fallback, uniform or blended). The mini-batch KD term averages these:
\[
\mathcal{L}_{KD}
=
B^{-1}\sum_{b=1}^{B}\bar{\mathcal{L}}_{KD}^{(b)}.
\]
Because \(w_i^{(b)}\) is computed per sample, different examples in the same
mini-batch can emphasize different teachers.
Figure~\ref{fig:grace-sample-specific-weighting} illustrates this behavior for
text-heavy, chart-heavy and ambiguous samples.

\begin{figure}[!htbp]
    \centering
    \includegraphics[width=\linewidth]{figures/grace_sample_specific_weighting.png}
    \caption[Sample-specific weighting.]{Sample-specific weighting.}
    \label{fig:grace-sample-specific-weighting}
\end{figure}

\FloatBarrier

Because each per-teacher loss uses Byte-Trie Wasserstein matching, this term
stays valid across heterogeneous tokenizers without requiring aligned token
indices.

The complete \methodname{} objective is
\begin{equation}
\mathcal{L}
=
\mathcal{L}_{CE}
+
\alpha_{\mathrm{KD}}\mathcal{L}_{KD}
+
\lambda_{\mathrm{ent}}\mathcal{L}_{ent}
+
\lambda_{z}\mathcal{L}_{z},
\label{eq:final-objective}
\end{equation}
where $\mathcal{L}_{CE}$ anchors the student to supervised answer tokens,
$\mathcal{L}_{KD}$ transfers routed teacher supervision and $\mathcal{L}_{ent}$
together with $\mathcal{L}_{z}$ regularize the router. Only $\theta$ and $\phi$
are updated.

\begin{algorithm}[H]
\caption{One GRACE training step}
\label{alg:grace-training-step}
\begin{algorithmic}[1]
\Require Mini-batch \(\mathcal{B}=\{(x_b,y_b)\}_{b=1}^{B}\), frozen teachers
\(\{T_i\}_{i=1}^{N}\), student \(S_\theta\), router \(G_\phi\)
\State Run the student on \(\mathcal{B}\) to obtain logits
\(\mathbf{z}_s^{(b)}\), hidden states \(\mathbf{H}_s^{(b)}\) and supervised
loss \(\mathcal{L}_{CE}\)
\For{each sample \(b\)}
    \State Pool hidden states at answer positions to form \(\mathbf{h}^{(b)}\)
    \State Compute router logits
    \(\mathbf{r}^{(b)}=G_\phi(\mathbf{h}^{(b)})\) and probabilities
    \(\mathbf{p}^{(b)}=\mathrm{softmax}(\mathbf{r}^{(b)})\)
    \State Select routed set
    \(\mathcal{R}_b=\mathrm{TopK}(\mathbf{r}^{(b)},\min(k_{\mathrm{route}},N))\)
    \State Renormalize routed weights to obtain \(\hat{\mathbf{p}}^{(b)}\)
\EndFor
\For{each teacher \(T_i\) selected by at least one sample}
    \State Load cached teacher logits \(\mathbf{z}_t^{(b,i)}\)
    \State Compute \(\mathcal{L}_{KD}^{(b,i)}\) with Byte-Trie Wasserstein
    matching on aligned answer positions
    \State Compute teacher-level gradient \(\mathbf{g}_i\) and agreement score
    \(s_i\)
\EndFor
\State Smooth agreement scores with EMA and construct active sets
\(\mathcal{A}_b\)
\State Compute final teacher weights \(w_i^{(b)}\) using fallback,
uniform or geometric blend rules
\State Aggregate routed KD for each sample
\Statex \[
\bar{\mathcal{L}}_{KD}^{(b)}
=
\sum_{i\in\mathcal{R}_b}w_i^{(b)}\mathcal{L}_{KD}^{(b,i)}
\]
\State Optimize the final objective
\Statex \[
\mathcal{L}
=
\mathcal{L}_{CE}
+
\alpha_{\mathrm{KD}}\frac{1}{B}\sum_{b=1}^{B}\bar{\mathcal{L}}_{KD}^{(b)}
+
\lambda_{\mathrm{ent}}\mathcal{L}_{ent}
+
\lambda_z\mathcal{L}_z
\]
\end{algorithmic}
\end{algorithm}
