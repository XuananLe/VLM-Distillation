\chapter{Proposed Method}
\label{chap:proposed-method}

This chapter presents \textbf{\gracefull{} (\gracename{})} by first defining
the heterogeneous multi-teacher distillation setting, then introducing the
\textbf{trie-Wasserstein KD loss}, \textbf{teacher routing network},
\textbf{gradient-agreement refinement mechanism} and \textbf{final training
objective}. The method targets vocabulary mismatch, variable teacher
usefulness across samples and KD gradients that conflict with the supervised
objective, with each component correcting one failure that the previous
component cannot fix.

\section{Method Overview and Problem Formulation}
\label{sec:method-overview-formulation}

We consider multimodal understanding tasks that require reading image
text, understanding the question and generating an answer sequence
\cite{singh2019vqamodelsread,mathew2021docvqadatasetvqadocument,masry2022chartqabenchmarkquestionanswering}.
The training set is
\(\mathcal{D}=\{(x_n,y_n)\}_{n=1}^{N_{\mathrm{data}}}\), where \(x_n\)
is a multimodal input and \(y_n\) is the target answer sequence.
Let \(S_{\theta}\) denote the student VLM with trainable parameters
\(\theta\), let \(G_{\phi}\) denote the trainable teacher router with
parameters \(\phi\) and let \(\mathcal{T}=\{T_i\}_{i=1}^{N}\) be the frozen
teacher pool. For each sample \(b\), the student produces logits
\(\mathbf{z}_s^{(b)}\) and teacher \(T_i\) provides teacher logits
\(\mathbf{z}_t^{(b,i)}\).

This formulation treats teacher choice as part of the learning problem, not as
a fixed preprocessing decision. In a heterogeneous teacher pool, a model that is
useful for one image-question pair may be less useful for another. A teacher
specialized for document layout may provide useful supervision for forms and
receipts, while a different teacher may be more suitable for natural scene text
or chart reasoning. At the same time, teacher logits cannot be compared to
student logits by token index when their tokenizers differ. The method must
therefore solve three coupled problems during training: compare teacher and
student output distributions across different vocabularies, select a small set
of relevant teachers for each sample and suppress teacher signals whose
gradients conflict with the supervised answer objective. GRACE addresses these
problems by combining tokenizer-agnostic trie-Wasserstein matching,
student-conditioned sparse teacher routing and gradient-agreement refinement.

Figure~\ref{fig:grace-architecture} summarizes the full training pipeline. The
diagram should be read from left to right. The left block contains the student,
the frozen teacher pool and the sample-level quantities produced by the forward
pass: student logits, hidden states and the supervised cross-entropy loss. The
middle block contains the two mechanisms that produce candidate teacher
supervision. Trie-Wasserstein KD computes a per-teacher distillation loss over a
shared byte trie, enabling tokenizer-agnostic output matching even when teacher
and student vocabularies are different. In parallel, the teacher routing network
maps pooled student hidden states to sparse routing weights and selects a small
subset of candidate teachers for the current sample. The right block applies
gradient-agreement refinement. It compares each routed teacher's KD gradient
with the supervised CE gradient, smooths the agreement signal and converts the
routed scores into final KD weights.

The method is organized around four components. \textbf{Trie-Wasserstein KD}
computes per-teacher distillation losses over a shared byte trie, so tokens are
matched by decoded lexical structure, not by vocabulary index. The
\textbf{teacher routing network} selects a sparse subset of candidate teachers
from student-side hidden states at each training step.
\textbf{Gradient-agreement refinement} adjusts the routed teacher weights based
on how well each teacher's distillation gradient aligns with the supervised
objective. Finally, the \textbf{training objective} combines supervised
cross-entropy, routed KD and router auxiliary losses into a single end-to-end
update. Together, they extend sparse expert routing and token-level logit
supervision to the heterogeneous multi-teacher VLM setting, where teachers and
student may use different tokenizers and vocabularies
\cite{shazeer2017outrageouslylargeneuralnetworks,fedus2022switchtransformersscalingtrillion,zhu2021studentcustomized}.

A GRACE update starts from a mini-batch
\(\mathcal{B}=\{(x_b,y_b)\}_{b=1}^{B}\) and a frozen teacher pool
\(\mathcal{T}=\{T_i\}_{i=1}^{N}\). The student first produces the logits,
hidden states and supervised cross-entropy loss for the answer tokens. The
router then uses the pooled student hidden state to select a sparse routed set
\(\mathcal{R}_b\) for each sample. For every selected teacher, trie-Wasserstein
KD computes a per-teacher loss \(\mathcal{L}_{KD}^{(b,i)}\), using the shared
byte-trie geometry to compare student and teacher output distributions across
different tokenizers. Gradient-agreement refinement then filters and reweights
the routed teachers by comparing each teacher-specific KD gradient with the
supervised CE gradient. At a high level, the routed KD signal for sample \(b\)
is the weighted combination of teacher-specific losses:
\[
\bar{\mathcal{L}}_{KD}^{(b)}
=
\sum_{i\in\mathcal{R}_b}
w_i^{(b)}\mathcal{L}_{KD}^{(b,i)}.
\]
The final weights \(w_i^{(b)}\) are determined by both the router and the
gradient-agreement refinement step. This decomposition separates teacher
selection from teacher validation: routing proposes teachers that appear
relevant to the sample, while gradient agreement checks whether their current
KD directions are compatible with the supervised learning objective. The
resulting KD term is then combined with CE and router regularization in one
optimization objective. The main notation used throughout the method is listed
in Table~\ref{tab:notation}.

\section{Trie-Wasserstein Cross-Tokenizer Distillation}
\label{sec:trie-wasserstein-distillation}

\subsection{Supervised Answer Tokens}

Distillation is applied only on \textbf{supervised answer tokens}, not on prompt
tokens. For sample \(b\), let \(\Omega_b^{CE}\) denote the student positions
whose labels are not ignored. For teacher \(T_i\), let \(\Omega_{b,i}^{KD}\)
denote the matched answer positions after masking ignored labels on both
student and teacher sides and truncating both spans to a common length. This is
a position-wise approximation across tokenizers: after answer-span
preprocessing, the \(j\)-th student and teacher answer positions are treated as
corresponding positions. Trie-Wasserstein matching handles the token-distribution
mismatch at each aligned position, while sequence-level byte alignment remains
outside the objective. Restricting distillation to answer positions avoids
wasting capacity on prompt formatting, padding and instruction wording, where
teacher and student distributions carry no task-relevant signal.

\subsection{Shared Byte Trie}

Direct token-index matching assumes that the \(k\)-th coordinate of the teacher
distribution and the \(k\)-th coordinate of the student distribution refer to
the same decoded token. This assumption fails when tokenizers differ: the same
vocabulary index may correspond to unrelated token strings in the teacher and
student vocabularies. GRACE maps decoded teacher and student token strings into
a \textbf{shared UTF-8 byte trie}, so tokens live in a shared prefix tree, not
arbitrary vocabulary-index space. Tokens with common byte prefixes share the
same initial trie path even if their tokenizer IDs are unrelated, allowing
probability mass from different vocabularies to be compared through shared
decoded-string structure.

For each sample \(b\), token position \(j \in \Omega_{b,i}^{KD}\) and teacher \(T_i\), let
\(\mathbf{z}_{s,j}^{(b)} \in \mathbb{R}^{V_s}\) be the student logits and
\(\mathbf{z}_{t,j}^{(b,i)} \in \mathbb{R}^{V_i}\) be the teacher logits.
The student and teacher probability distributions are
\begin{equation}
\mathbf{p}_{s,j}^{(b)}
=
\mathrm{softmax}\!\left(\frac{\mathbf{z}_{s,j}^{(b)}}{\tau_s}\right),
\qquad
\mathbf{p}_{t,j}^{(b,i)}
=
\mathrm{softmax}\!\left(\frac{\mathbf{z}_{t,j}^{(b,i)}}{\tau_t}\right),
\end{equation}
where \(\tau_s\) and \(\tau_t\) are the student and teacher temperatures.
In the sparse computation, ignored token IDs are masked before normalization so
special and extended tokens do not receive probability mass in the trie.

Before insertion, each tokenizer piece is canonicalized into lexical content
and optional boundary metadata. Visible boundary markers such as GPT-2-style
space markers, SentencePiece space markers, WordPiece \texttt{\#\#} markers
and BPE \texttt{</w>} markers are stripped from the content string and recorded
as boundary type. If the tokenizer decoder exposes leading whitespace directly,
GRACE records that whitespace as a boundary signal and stores the stripped
content bytes. The content is decoded, Unicode normalized and encoded as UTF-8
bytes. This keeps tokenizer conventions from splitting the shared content path
at the root. Marker-only pieces remain explicit content pieces, so
canonicalization never removes a token from the trie.

Each canonical content string is terminated with an EOS sentinel. The sentinel
separates complete tokens from strict prefixes, so \texttt{doc} and
\texttt{document} remain distinct leaves even though they share an initial
path. If a tokenizer boundary marker was removed during canonicalization, GRACE
adds a boundary edge after the EOS sentinel with weight
\(\eta_{\mathrm{boundary}}\). This design shifts the comparison away from
identical token IDs and keeps probability mass on similar decoded strings
close, while treating whitespace and word-boundary conventions as small
tokenizer-specific differences.

The trie defines a geometry over decoded token strings, illustrated in
Figure~\ref{fig:grace-trie-shared} for the pairs
\texttt{document}/\texttt{receipt} and \texttt{doc}/\texttt{rece}. That
geometry is well suited to OCR-heavy VQA, where correct and near-correct
answers often differ through prefixes, suffixes, spaces or number formats. For
example, \texttt{<space>cat}, \texttt{cat} and \texttt{\#\#cat} share the same
content bytes for \texttt{cat}, with boundary edges recording tokenizer
conventions separately. For a normal content-byte or EOS edge \(e\), let
\(d(e)\) be its depth.
GRACE assigns edge weights as follows:
\begin{equation}
w(e)=
\begin{cases}
\rho_{\mathrm{trie}}^{d(e)-1}, & e \in E_{\mathrm{content}}\cup E_{\mathrm{EOS}},\\
\eta_{\mathrm{boundary}}, & e \in E_{\mathrm{boundary}}.
\end{cases}
\label{eq:tw_edge_weight}
\end{equation}
where \(0<\rho_{\mathrm{trie}}<1\) and
\(\eta_{\mathrm{boundary}}\ge 0\). Here \(E_{\mathrm{boundary}}\) contains
optional marker edges for space, continuation and end-of-word metadata. The
first content edge from the root has
weight \(1\) and deeper content edges decay geometrically. This makes shared
prefixes cheaper to transport across than unrelated byte paths, while boundary
edges keep space and continuation markers close to their underlying content.
The loss therefore penalizes how far the student's probability mass must move
through the shared lexical tree to resemble the teacher's mass, not whether the
student assigns probability to the same token indices. The weighting still
preserves a valid tree metric
\cite{takezawa2021supervisedtreewasserstein,peyre2019computationaloptimaltransport}
and different tokenizers may stop at different depths while still sharing the
same byte-prefix edges whenever their decoded token strings overlap in
byte-prefix structure.

\subsection{Trie-Wasserstein Objective}

The shared byte trie induces a tree metric over decoded token strings. Let
\(\mathcal{V}_s\) and \(\mathcal{V}_t\) denote the student and teacher token
vocabularies being compared at a given answer position and let \(\pi(v)\)
denote the trie path of decoded token \(v\). For an edge \(e\), the student
and teacher subtree masses are
\[
m_s(e)
=
\sum_{\substack{v\in\mathcal{V}_s\\ e\in\pi(v)}} p_s(v),
\qquad
m_t(e)
=
\sum_{\substack{u\in\mathcal{V}_t\\ e\in\pi(u)}} p_t(u).
\]
\(m_s(e)\) and \(m_t(e)\) measure how much probability mass each distribution
assigns to token paths passing through edge \(e\). The \(W_1\)
optimal transport distance between teacher and student token distributions on
the trie can then be written as a weighted sum of subtree-mass imbalances. The
loss rewards lexical closeness, not exact token-ID equality:
\begin{equation}
W_T(p_s,p_t)
=
\sum_{e\in E}
w(e)\left|m_s(e)-m_t(e)\right|.
\label{eq:trie-wasserstein-objective}
\end{equation}
This form follows from the standard \(W_1\) Kantorovich optimal transport
problem under the trie-induced tree metric
\cite{peyre2019computationaloptimaltransport,takezawa2021supervisedtreewasserstein}.
The full proof is provided in Appendix~\ref{app:tree-wasserstein-proof}. The
sparse construction below applies the same formula to a bounded
top-\(K_{\mathrm{TW}}\) support with a residual tail edge.

\subsection{Sparse Support and Residual Tail Edge}

Equation~\eqref{eq:trie-wasserstein-objective} is exact on the complete shared
trie, but evaluating every vocabulary token at every answer position is
expensive. GRACE builds a \textbf{sparse augmented trie}, so most
useful distributional information, concentrated in high-probability tokens, is
captured exactly. The tail edge handles the remainder: without it, omitted mass
would silently disappear, making the teacher appear more confident than it
really is and distorting the transport distance. At each aligned answer
position, it masks ignored vocabulary entries, retains the
\textbf{top-\(K_{\mathrm{TW}}\) student and teacher tokens} and inserts those
tokens through their canonical content paths, followed by EOS and any optional
boundary edge.
Probability mass outside the retained sets is not discarded. It is collapsed
into a single \textbf{residual tail edge}.
This gives an exact distance on the collapsed sparse trie and it approximates
the complete trie distance by representing all omitted vocabulary mass with one
tail atom.

Let \(K_{\mathrm{TW}}\) denote the sparse trie support size. Let
\(\mathcal{V}_s^\star\) and \(\mathcal{V}_t^\star\) denote the non-ignored
student and teacher vocabularies. Before constructing the sparse trie, the
student and teacher probabilities are renormalized over the non-ignored
vocabularies so that the retained and residual masses form valid
distributions. Operationally, ignored entries are excluded from the softmax
normalizer before top-\(K_{\mathrm{TW}}\) selection.
Let
\(\mathcal{K}_{s,j}^{(b)}\subset\mathcal{V}_s^\star\) and
\(\mathcal{K}_{t,j}^{(b,i)}\subset\mathcal{V}_t^\star\) be the retained token
sets. The residual mass assigned to the tail edge is
\begin{equation}
r_{s,j}^{(b)}
=
1-\sum_{v\in\mathcal{K}_{s,j}^{(b)}}p_{s,j}^{(b)}(v),
\qquad
r_{t,j}^{(b,i)}
=
1-\sum_{v\in\mathcal{K}_{t,j}^{(b,i)}}p_{t,j}^{(b,i)}(v).
\end{equation}
Let \(\pi(v)\) be the trie path for token \(v\), including canonical content
edges, the EOS edge and any optional boundary edge. Let
\(e_{\mathrm{tail}}\) be the global residual tail edge with
\(w(e_{\mathrm{tail}})=1\). For any active trie edge \(e\), the sparse subtree
masses are
\begin{equation}
m_{s,j}^{(b)}(e)
=
\sum_{\substack{v\in\mathcal{K}_{s,j}^{(b)}\\e\in\pi(v)}}
p_{s,j}^{(b)}(v)
+
\mathbf{1}[e=e_{\mathrm{tail}}]\,r_{s,j}^{(b)},
\end{equation}
\begin{equation}
m_{t,j}^{(b,i)}(e)
=
\sum_{\substack{v\in\mathcal{K}_{t,j}^{(b,i)}\\e\in\pi(v)}}
p_{t,j}^{(b,i)}(v)
+
\mathbf{1}[e=e_{\mathrm{tail}}]\,r_{t,j}^{(b,i)}.
\end{equation}
The token-level trie-Wasserstein loss is
\begin{equation}
\ell_{TW}\!\left(\mathbf{z}_{s,j}^{(b)},\mathbf{z}_{t,j}^{(b,i)}\right)
=
\sum_{e\in\mathcal{E}_{act,j}^{(b,i)}}
w(e)\,
\left|
m_{s,j}^{(b)}(e)-m_{t,j}^{(b,i)}(e)
\right|,
\label{eq:token_tw}
\end{equation}
where \(\mathcal{E}_{act,j}^{(b,i)}\) contains the active canonical content
edges, EOS edges, optional boundary edges and the residual tail edge from the
student and teacher supports. Before the absolute value is applied,
\(m_{s,j}^{(b)}(e)-m_{t,j}^{(b,i)}(e)\) is positive when edge \(e\) carries more
student mass and negative when it carries more teacher mass.

The per-sample, per-teacher KD loss is the mean over supervised answer
tokens:
\begin{equation}
\mathcal{L}_{KD}^{(b,i)}
=
\frac{1}{|\Omega_{b,i}^{KD}|}
\sum_{j\in\Omega_{b,i}^{KD}}
\ell_{TW}\!\left(\mathbf{z}_{s,j}^{(b)},\mathbf{z}_{t,j}^{(b,i)}\right).
\label{eq:per_teacher_tw}
\end{equation}

\textbf{Complexity analysis.}
The shared byte trie is built once with time and memory cost
\(O(V_s \bar{L}_s + V_t \bar{L}_t)\), where \(V_s\) and \(V_t\) are the
student and teacher vocabulary sizes and \(\bar{L}_s\) and \(\bar{L}_t\) are
the average canonical path lengths, including EOS and optional boundary edges.
For one aligned answer position, extracting the
top-\(K_{\mathrm{TW}}\) student and teacher tokens costs
\(O(V_s\log K_{\mathrm{TW}} + V_t\log K_{\mathrm{TW}})\) with heap-based
selection. Given the retained token sets, sparse subtree-mass accumulation
walks only the retained canonical token paths and the residual tail edge, costing
\(O(K_{\mathrm{TW}}\bar{L}_s + K_{\mathrm{TW}}\bar{L}_t + A)\), where \(A\)
is the number of active trie edges. If the implementation explicitly sorts or
deduplicates active edge indices, this adds an \(O(A\log A)\) term. Otherwise,
indexed accumulation gives an \(O(A)\) edge-aggregation cost. Runtime memory is
\(O(E + P_s + P_t + A)\), where \(E\) is the number of trie
edges and \(P_s\) and \(P_t\) are the stored student and teacher path-index
arrays. Unlike dense optimal transport, the sparse computation does not materialize a
\(|V_s| \times |V_t|\) transport matrix.

\section{Teacher Routing Network}
\label{sec:teacher-routing-network}

\subsection{Router Architecture}

With multiple teachers, uniform averaging ignores sample-specific teacher
strengths: a document question, a chart question and a scene-text question may
each benefit from a different expert and the student's own hidden states are
the most direct signal of which kind of example is being processed. This makes
GRACE routing different from sparse mixture-of-experts routing in standard
transformers: MoE routing chooses which expert computes the forward pass,
while GRACE routing chooses which frozen external teacher shapes the student's
learning signal. GRACE therefore attaches a \textbf{teacher routing network} to the
linear language-model head, so the gate operates on the text hidden state
immediately before token prediction. The full pipeline from pooled student
features to sparse top-\(k\) teacher selection is shown in
Figure~\ref{fig:deep-router}.

\begin{figure}
\centering
\includegraphics[width=\linewidth]{figures/deep-router.pdf}
\caption{Teacher routing network.}
\label{fig:deep-router}
\end{figure}

Let \(\mathbf{H}_s^{(b)}\) denote the student hidden states captured
immediately before the language-model head for sample \(b\). These are pooled
over supervised answer positions to form the \textbf{routing feature}:
\begin{equation}
\mathbf{h}^{(b)} = \mathrm{Pool}\!\left(\mathbf{H}_s^{(b)}\right).
\end{equation}
Pooling over answer positions captures what the student currently represents
about the output, which is more informative than pooling over the full
sequence. The routing feature is also student-state-dependent, not only
dataset-dependent: the same image-question pair can produce a different routing
decision as the student's representations evolve during training, allowing
teacher selection to adapt continuously. The operation uses the mean over
supervised answer positions and requires at least one supervised answer token
per sample.

A learned SwiGLU-style MLP router \(G_{\phi}(\cdot)\) maps the routing feature
to gate logits,
\begin{equation}
\mathbf{r}^{(b)} = G_{\phi}\!\left(\mathbf{h}^{(b)}\right).
\label{eq:router-logits}
\end{equation}
These logits are converted to soft routing weights by softmax:
\begin{equation}
\mathbf{p}^{(b)} = \mathrm{softmax}\!\left(\mathbf{r}^{(b)}\right),
\label{eq:router-softmax}
\end{equation}
where \(p_i^{(b)}\) is the initial gate weight for teacher \(T_i\). The router
then masks to the top-\(k_{\mathrm{route}}\) teachers and renormalizes the
selected weights. The internal stack uses LayerNorm, an up-projection, a
gate-value split, SiLU gating and a down-projection, keeping score computation
dense while teacher use remains sparse after top-\(k\) masking.

\subsection{Top-k Routing}

Soft routing weights are dense, but distillation should not use every teacher
for every sample. GRACE converts them into a \textbf{sparse routed set} by
selecting the highest-scoring teachers for sample \(b\):
\begin{equation}
\mathcal{C}_b=\mathrm{TopK}(\mathbf{r}^{(b)},\min(k_{\mathrm{route}},N)).
\label{eq:topk-candidate-set}
\end{equation}
The candidate set \(\mathcal{C}_b\) serves as the routed teacher set
\(\mathcal{R}_b\). With
\(m_i^{(b)}=\mathbf{1}[i\in\mathcal{C}_b]\) denoting the top-\(k\) assignment
mask, non-selected weights are zeroed and the remaining softmax weights are
renormalized:
\begin{equation}
\hat{p}_i^{(b)}
=
\frac{m_i^{(b)} p_i^{(b)}}{\sum_{j=1}^{N} m_j^{(b)} p_j^{(b)}}.
\label{eq:constrained_gate_weights}
\end{equation}
Top-\(k\) routing makes supervision sparse and sample-specialized. Routing
alone is not sufficient, however. A teacher can look relevant because
its domain matches the input while its gradient still conflicts with the
supervised target. For example, a document-specialized teacher may assign high
probability to a plausible but incorrect field value. Gradient-agreement
refinement, introduced in Section~\ref{sec:gradient-agreement-refinement},
addresses this residual failure. Figure~\ref{fig:grace-routing-dynamics}
contrasts dense gate probabilities with the sparse routed assignment. The
logged assignment rate records how often each teacher appears in the routed
set.

\subsection{Router Entropy and Z-Loss}

Two auxiliary terms regularize teacher selection. \textbf{Entropy
regularization} is implemented as a negative-entropy term that discourages
premature routing collapse:
\begin{equation}
\mathcal{L}_{ent}
=
-\frac{1}{B}\sum_{b=1}^{B} H(\mathbf{p}^{(b)}).
\end{equation}
The \textbf{router \(z\)-loss} keeps router logits numerically well behaved:
\begin{equation}
\mathcal{L}_{z}
=
\frac{1}{B}\sum_{b=1}^{B}
\left(\log \sum_{i=1}^{N} e^{r_i^{(b)}}\right)^2.
\end{equation}
Both terms are pure stabilizers: entropy discourages the router from collapsing
onto a single teacher too early, while z-loss keeps routing logits numerically
controlled. Neither competes with the CE or KD objectives.

\section{Gradient-Agreement Refinement}
\label{sec:gradient-agreement-refinement}

Routed teachers may still conflict with the supervised objective after teacher
selection. \textbf{Gradient-agreement refinement} addresses this by scoring
each teacher's KD direction against the supervised CE direction and using those
scores inside the routed candidate set. Routing answers which teacher seems
relevant to this sample. Gradient agreement answers which of those teachers is
currently compatible with learning the correct answer. The two checks are
complementary because domain relevance does not guarantee gradient
compatibility, as established in
Section~\ref{subsec:gradient-conflict}.

\subsection{Gradient Agreement Scoring}

Let \(\Theta\subseteq\theta\) denote the trainable student parameters used by the
optimizer. To score each teacher, GRACE compares its
\textbf{teacher-specific KD gradient} against the \textbf{supervised CE
gradient} in student-parameter space. The CE gradient is
\begin{equation}
\mathbf{g}_{CE}
=
\nabla_{\Theta}\mathcal{L}_{CE}.
\end{equation}
For teacher \(T_i\), the KD gradient comes from that teacher's mean
distillation loss over the full mini-batch:
\begin{equation}
\mathbf{g}_{i}
=
\nabla_{\Theta}
\left(
\frac{1}{B}\sum_{b=1}^{B}\mathcal{L}_{KD}^{(b,i)}
\right).
\end{equation}
Here, \(\mathcal{L}_{KD}^{(b,i)}\) is the trie-Wasserstein loss from
Equation~\ref{eq:per_teacher_tw}. These gradients score teacher compatibility
while the final parameter update is still computed from the full training
objective. As established in
Section~\ref{subsec:gradient-conflict}, a teacher whose KD gradient opposes
the CE gradient pulls the student away from the correct answer even when the
router selected it confidently.

\subsection{Agreement Scores and Active Set}

We quantify how well supervised learning and KD are directionally aligned using cosine similarity:
\begin{equation}
s_i
=
\frac{
\langle \mathbf{g}_{CE},\mathbf{g}_i\rangle
}{
\max\!\left(\|\mathbf{g}_{CE}\|_2\|\mathbf{g}_i\|_2,\epsilon_{\mathrm{num}}\right)
}.
\label{eq:grace-gradient-agreement-score}
\end{equation}
The agreement score \(s_i\) is \textbf{teacher-level} within the current
mini-batch and is broadcast across samples. Sample dependence enters through
the routed set \(\mathcal{R}_b\), routed weights \(\hat{\mathbf{p}}^{(b)}\) and
active set \(\mathcal{A}_b\). To combine teacher-level agreement with
sample-specific routing, GRACE first converts the agreement score into a binary
teacher flag:
\begin{equation}
\tilde{a}_i = \mathbf{1}[s_i > \delta],
\label{eq:grace-teacher-active-flag}
\end{equation}
where \(\delta\) is the GRACE threshold. This flag is then intersected with
the routed teacher set for each sample:
\begin{equation}
a_i^{(b)}=\mathbf{1}[i\in\mathcal{R}_b]\tilde{a}_i,
\qquad
\mathcal{A}_b=\{i\in\mathcal{R}_b:a_i^{(b)}=1\}.
\label{eq:grace-sample-active-set}
\end{equation}
The intersection with \(\mathcal{R}_b\) keeps the search inside the routed
candidates: routing narrows the pool first and gradient agreement filters
within it.
The threshold \(\delta\) is applied to the raw score \(s_i\), while the
EMA-smoothed score \(\hat{s}_i\) controls score-softmax weighting and fallback
spread. Agreement scores act as non-differentiable routing statistics, so the
final optimization step does not backpropagate through the gradient-agreement
computation itself or treat the scoring procedure as an additional trainable
path.

\subsection{Warmup, EMA Smoothing and Score Weights}

Teacher weights can change abruptly when agreement scores are estimated from a
single mini-batch. GRACE stabilizes this step with \textbf{warmup},
\textbf{EMA smoothing} and \textbf{score-softmax weighting}. Let
\(\rho_g \in [0,1]\) denote the warmup ratio relative to the total number of
training steps. During the first \(\rho_g T_{\mathrm{train}}\) steps, routed
gate weights are left unchanged:
\begin{equation}
w_i^{(b)}=\hat{p}_i^{(b)}.
\label{eq:grace_warmup_router_weights}
\end{equation}
Early in training, the student's representations and the router's assignments
are both still changing, so gradient-based filtering applied too soon risks
rejecting useful teachers because the agreement scores are not yet reliable.
Warmup prevents the agreement mechanism from overfitting to early gradient
noise and missing genuine teacher usefulness.
After warmup, routed teachers are refined with a smoothed score distribution.
Let \(\bar{s}_i^{\mathrm{prev}}\) be the running exponential moving average
(EMA) of past batch means for teacher \(T_i\) and let
\(\beta_{\mathrm{EMA}}\) be its decay. The smoothed score is
\begin{equation}
\hat{s}_i
=
\beta_{\mathrm{EMA}} \bar{s}_i^{\mathrm{prev}}
+
(1-\beta_{\mathrm{EMA}}) s_i.
\label{eq:grace-ema-score}
\end{equation}
EMA smoothing turns gradient agreement from a momentary vote into a reputation
score. For nonempty active sets, smoothed scores are converted into a
score-softmax weight vector over \(\mathcal{A}_b\):
\begin{equation}
\omega_i^{(b)}
=
\frac{
\exp(\beta_{\mathrm{score}}\hat{s}_i) \mathbf{1}[i \in \mathcal{A}_b]
}{
\sum_{j=1}^{N}
\exp(\beta_{\mathrm{score}}\hat{s}_j) \mathbf{1}[j \in \mathcal{A}_b]
},
\label{eq:grace_softmax}
\end{equation}
\(\beta_{\mathrm{score}}\) controls how sharply the highest-scoring active
teacher is preferred, setting up the fallback and blending cases below.

\subsection{Weight Blending and Fallback}

Final KD weights are assigned through three mutually exclusive cases for each
sample. These cases prevent the refinement step from overreacting when
agreement evidence is missing or weak.

\textbf{No active teacher.} If \(\mathcal{A}_b=\emptyset\), the routed
weights are retained:
\begin{equation}
w_i^{(b)}=\hat{p}_i^{(b)}.
\label{eq:no-active-teacher-fallback}
\end{equation}

\textbf{Low-confidence scores.} If active teachers exist but their
smoothed scores are too close, uniform weights are used over the active set.
The score range is
\begin{equation}
\Delta^{(b)}
=
\max_{i \in \mathcal{A}_b}\hat{s}_i
-
\min_{i \in \mathcal{A}_b}\hat{s}_i.
\end{equation}
If \(\mathcal{A}_b\neq\emptyset\) and
\(\Delta^{(b)} < \epsilon_{\mathrm{fb}}\), then
\begin{equation}
w_i^{(b)}
=
\frac{\mathbf{1}[i \in \mathcal{A}_b]}
{|\mathcal{A}_b|}.
\label{eq:alignment_fallback}
\end{equation}

\textbf{Confident scores.} Otherwise, router weights are blended with
score weights. Let
\(\lambda_{\mathrm{blend}} \in [0,1]\) be the router-blend exponent. The
unnormalized blended weights are
\begin{equation}
\tilde{w}_i^{(b)}
\propto
\left(\hat{p}_i^{(b)}\right)^{\lambda_{\mathrm{blend}}}
\left(\omega_i^{(b)}\right)^{1-\lambda_{\mathrm{blend}}},
\label{eq:blended-weights-unnormalized}
\end{equation}
followed by normalization over the active routed teachers:
\begin{equation}
w_i^{(b)}
=
\frac{\tilde{w}_i^{(b)} \mathbf{1}[i \in \mathcal{A}_b]}
{\sum_{j=1}^{N}\tilde{w}_j^{(b)} \mathbf{1}[j \in \mathcal{A}_b]}.
\label{eq:effective_teacher_weights}
\end{equation}
Equations~\ref{eq:grace_softmax}, \ref{eq:alignment_fallback} and
\ref{eq:effective_teacher_weights} define the gradient-refinement operator:
the router chooses \(\mathcal{R}_b\), agreement filtering narrows it to
\(\mathcal{A}_b\) and final weights are retained from the router, assigned
uniformly or geometrically blended depending on confidence. These regimes are
shown in Figure~\ref{fig:grace-alignment-cases}.

\vspace{-0.4em}

\begin{figure}
    \centering
    \includegraphics[width=\linewidth]{figures/grace_alignment_cases.png}
    \caption[Representative KD weighting regimes.]{Representative KD weighting regimes.}
    \label{fig:grace-alignment-cases}
\end{figure}

This design keeps teacher selection sparse throughout: gradient-agreement
refinement can narrow the routed set but never expands it, so KD cost remains
bounded by \(k_{\mathrm{route}}\) teachers per sample.

\section{Routed KD Aggregation and Final Objective}
\label{sec:routed-kd-final-objective}
\label{sec:final-objective}

The final teacher weights \(w_i^{(b)}\) combine the routed teacher set
\(\mathcal{R}_b\), router weights \(\hat{\mathbf{p}}^{(b)}\) and
gradient-agreement scores. The objective aggregates routed per-teacher KD
losses into a sample-level term, averages those terms across the mini-batch and
then adds supervised and router-regularization losses.

\textbf{Sample-level aggregation.} For sample \(b\), only teachers in the
routed set \(\mathcal{R}_b\) contribute to the KD loss:
\begin{equation}
\bar{\mathcal{L}}_{KD}^{(b)}
=
\sum_{i\in\mathcal{R}_b} w_i^{(b)}\mathcal{L}_{KD}^{(b,i)}.
\label{eq:sample-kd-aggregation}
\end{equation}
Non-routed teachers have zero contribution, while routed teachers are weighted
by the fallback, uniform-active or blended rule. All post-routing refinement
decisions enter the optimization through \(w_i^{(b)}\).

\textbf{Batch-level aggregation.}
The mini-batch KD term averages the sample-level KD losses:
\begin{equation}
\mathcal{L}_{KD}
=
\frac{1}{B}\sum_{b=1}^{B}\bar{\mathcal{L}}_{KD}^{(b)}.
\label{eq:batch-kd}
\end{equation}
This scalar term supplies teacher supervision to the final objective. It stays
compatible with heterogeneous teachers because each per-teacher loss uses
trie-Wasserstein matching, which is tokenizer-agnostic and avoids direct
token-index KL divergence.

\textbf{Final objective.}
The complete \methodname{} objective is
\begin{equation}
\mathcal{L}
=
\mathcal{L}_{CE}
+
\alpha_{\mathrm{KD}}\mathcal{L}_{KD}
+
\lambda_{\mathrm{ent}}\mathcal{L}_{ent}
+
\lambda_{z}\mathcal{L}_{z}.
\label{eq:final-objective}
\end{equation}
The terms in this objective follow the dependency chain:
\(\mathcal{L}_{CE}\) is the compass that fixes the learning direction,
\(\mathcal{L}_{KD}\) provides the teacher map, routing chooses which map to
consult and gradient agreement checks whether the map currently points in the
compass direction.
The coefficient \(\alpha_{\mathrm{KD}}\) controls the strength
of teacher supervision, while \(\lambda_{\mathrm{ent}}\) and \(\lambda_z\)
control the auxiliary router losses. Only the student parameters \(\theta\) and
router parameters \(\phi\) are optimized, while all teacher parameters remain
frozen.
