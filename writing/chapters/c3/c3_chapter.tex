\chapter{GRACE: A Heterogeneous Multi-Teacher Distillation Framework}
\label{chap:proposed-method}

GRACE addresses three constraints that existing methods handle separately:
\textbf{vocabulary mismatch} between teacher and student, \textbf{variable teacher usefulness}
across samples and \textbf{KD gradients that conflict} with the supervised CE
objective. The three components are introduced in this order, with each one
addressing a constraint that the previous component leaves open.

\section{Method Overview and Problem Formulation}
\label{sec:method-overview-formulation}

We consider a training set
\[
\mathcal{D}=\{(x_n,y_n)\}_{n=1}^{N_{\mathrm{data}}},
\]
where \(x_n\) is a multimodal input and \(y_n\) is the target answer sequence.


Let \(S_{\theta}\) denote the student VLM with trainable parameters
\(\theta\), let \(G_{\phi}\) denote the trainable teacher router with
parameters \(\phi\) and let \(\mathcal{T}=\{T_i\}_{i=1}^{N}\) be the frozen
teacher pool. For each sample \(b\), the student produces logits
\(\mathbf{z}_s^{(b)}\) and teacher \(T_i\) provides logits
\(\mathbf{z}_t^{(b,i)}\).

Teacher and student output spaces use different token indices, so naive KD
compares unrelated vocabulary positions. Teacher usefulness is also
sample-dependent: a model strong at document layout need not be strong at
chart reasoning. Relevance alone is not enough: a teacher that appears well-matched to the
sample can still produce a KD gradient that pushes against the supervised CE
objective. GRACE addresses these constraints with \textbf{Byte-Trie
Wasserstein} matching, \textbf{sparse teacher routing} and
\textbf{gradient-agreement refinement}.

\caption[Overview of the GRACE architecture.]{Overview of the GRACE architecture.}
\label{fig:grace-architecture}
\end{figure}


The full pipeline is depicted in Figure~\ref{fig:grace-architecture}.
The router uses pooled student hidden states to select a sparse teacher subset.
The Byte-Trie Wasserstein Loss then computes a per-teacher loss by matching
decoded token paths through a shared byte trie. Gradient-agreement refinement
reweights the selected teachers by how well each teacher's KD gradient aligns
with the CE objective. The final objective combines supervised cross-entropy,
this routed KD signal and two router regularization terms
\cite{shazeer2017outrageouslylargeneuralnetworks,fedus2022switchtransformersscalingtrillion,zhu2021studentcustomized}.

A GRACE update starts from a mini-batch
\[
\mathcal{B}=\{(x_b,y_b)\}_{b=1}^{B}
\]
and the frozen teacher pool \(\mathcal{T}\). The student first
produces logits, hidden states and the supervised cross-entropy loss for the answer tokens. The
router then uses the pooled student hidden state to select a sparse routed set
\(\mathcal{R}_b\) for each sample. For every selected teacher, the Byte-Trie Wasserstein Loss computes a
per-teacher loss \(\mathcal{L}_{KD}^{(b,i)}\), comparing student and teacher
distributions via the shared byte trie.
Gradient-agreement refinement then adjusts routed teacher weights by
comparing each teacher's KD gradient with the supervised CE gradient. The routed KD signal for sample \(b\)
is the weighted combination of teacher-specific losses:
\[
\bar{\mathcal{L}}_{KD}^{(b)}
=
\sum_{i\in\mathcal{R}_b}
w_i^{(b)}\mathcal{L}_{KD}^{(b,i)}.
\]
The method introduces several hyperparameters
(\(\rho_{\mathrm{trie}}\), \(\eta_{\mathrm{boundary}}\), \(K_{\mathrm{TW}}\),
\(k_{\mathrm{route}}\), \(\beta_{\mathrm{EMA}}\), \(\lambda_{\mathrm{blend}}\)
and others). Hyperparameter values and sensitivity analysis are in
Appendix~\ref{app:experiment-parameters} and Section~\ref{sec:ablation}.

\section{Byte-Trie Wasserstein Distillation}
\label{sec:byte-trie-wasserstein-distillation}

The first obstacle in cross-tokenizer KD is that token indices are not
comparable across different vocabularies: index \(j\) in one model may decode
to an unrelated string in another. The Byte-Trie Wasserstein loss removes this
assumption by building a shared UTF-8 byte trie over all tokenizer vocabularies
and measuring transport cost through \textbf{byte-path proximity}.

For sample \(b\) and teacher \(T_i\), GRACE restricts KD to matched answer
positions \(\Omega_{b,i}^{KD}\), after masking ignored labels and truncating
student and teacher answer spans to a common length. Restricting to answer
positions aligns the distillation span with the supervised CE objective,
which also acts only on answer tokens. Applying KD across all sequence
positions would push the student's distribution on image and question tokens
that it is not trained to predict, introducing gradient noise outside the
supervised span. At each position
\(j \in \Omega_{b,i}^{KD}\), the student and teacher logits define softened
distributions
\[
p^{(b)}_{s,j}
=
\mathrm{softmax}\!\left(z^{(b)}_{s,j}/\tau_s\right),
\qquad
p^{(b,i)}_{t,j}
=
\mathrm{softmax}\!\left(z^{(b,i)}_{t,j}/\tau_t\right).
\]
Dividing by \(\tau > 1\) spreads probability mass across the vocabulary,
revealing the teacher's relative confidence over near-correct alternatives
rather than collapsing it onto the single argmax token. A token the teacher
ranks second or third with non-trivial probability signals that it is a
plausible alternative, providing a richer gradient signal than a one-hot
target would.
The computation proceeds in three steps. It precomputes \textit{canonical byte paths}
for all vocabulary tokens in a shared trie, retains \textit{sparse lexical supports} at
each answer position and computes the tree-Wasserstein loss from per-edge
subtree-mass imbalances. Visual placeholders and control tokens are excluded
from the trie comparison and handled through a separate non-text penalty.

\subsection{Shared Byte Trie}

Applying KD by token index requires aligned vocabularies, but with different
tokenizers the same index may correspond to unrelated decoded strings. GRACE
therefore builds one \textbf{UTF-8 byte trie} shared by the teacher and student
tokenizers. Each token piece is decoded, normalized and split into \textit{lexical
content} and \textit{boundary metadata}. The lexical content determines the main byte
path, while whitespace, continuation and end-word markers are represented as
low-cost boundary information rather than as separate root branches.

This \textbf{canonicalization} suppresses tokenizer artifacts during trie-based
matching: tokens with the same decoded content share byte-prefix edges even
when their tokenizers use different whitespace or continuation conventions.
An \textbf{EOS sentinel} is appended to each content path, which prevents prefix
collapse by making a complete token such as \texttt{doc} distinct from the
prefix of \texttt{document}. When boundary metadata is present, it is attached
after the terminal content path, so it can affect the cost without preventing
lexical prefixes from matching. Content and EOS edges receive weights that
decay with depth, while optional boundary edges receive a small fixed weight:
\begin{equation}
w(e)=
\begin{cases}
\rho_{\mathrm{trie}}^{d(e)-1}, & e \in E_{\mathrm{content}}\cup E_{\mathrm{EOS}},\\
\eta_{\mathrm{boundary}}, & e \in E_{\mathrm{boundary}}.
\end{cases}
\label{eq:tw_edge_weight}
\end{equation}
where \(0<\rho_{\mathrm{trie}}<1\), \(\eta_{\mathrm{boundary}}\ge 0\) and
\(d(e)\) is the edge depth. The decay encodes the intuition that early
divergence carries more semantic weight: two tokens that differ at depth 1
share no bytes and are completely unrelated, while two tokens that diverge
only at depth 5 share a long prefix and are morphological variants of the
same word. Since \(d_T\) sums only the symmetric-difference edges,
depth-decayed weights make this distinction precise because early-diverging
pairs accumulate more total edge weight than late-diverging ones.
The trie-induced distance between two tokens
\(u\) and \(v\) is the total weight of the edges on exactly one of their paths:
\begin{equation}
d_T(u,v)
=
\sum_{e\,\in\,\pi(u)\,\triangle\,\pi(v)}
w(e),
\label{eq:trie-token-distance}
\end{equation}
where \(\pi(u)\,\triangle\,\pi(v)\) is the symmetric difference of the two
edge sets. Tokens that share a long byte prefix have small \(d_T\), while
tokens with no shared prefix pay the full path weight. This metric is the ground
cost that the Wasserstein objective minimises, making it explicit why
\texttt{doc} and \texttt{document} are closer than \texttt{doc} and \texttt{xyz}
regardless of which tokenizer produced them
\cite{takezawa2021supervisedtreewasserstein,peyre2019computationaloptimaltransport}.

\texttt{doc}, \texttt{document}, \texttt{rece} and \texttt{receipt}.
The two document-related tokens share the path \texttt{d}$\to$\texttt{o}$\to$\texttt{c}

\(1,\rho_{\mathrm{trie}},\rho_{\mathrm{trie}}^2,\ldots\) with depth, so
the transport cost between any two tokens is proportional to the length of
the byte path they do \emph{not} share: tokens with long common prefixes
incur low transport cost regardless of which tokenizer produced them.

\subsection{Sparse Support and Residual Tail Edge}

The shared trie is built once from the tokenizer vocabularies, but evaluating
every token path at every answer position is computationally prohibitive.
GRACE therefore keeps only the top-\(K_{\mathrm{TW}}\) lexical student and
teacher tokens after masking ignored entries. The retained tokens reuse their
canonical trie paths, while unretained lexical probability mass is collapsed
into a \textbf{residual tail edge} \(e_{\mathrm{tail}}\). Non-text visual or control
tokens are not forced into the byte trie. Their probability mass is handled
outside the tree comparison so the transport geometry remains lexical.

Let \(K_{\mathrm{TW}}\) denote the sparse trie support size. Let
\(\mathcal{V}_{s,\mathrm{text}}^\star\) and
\(\mathcal{V}_{t,\mathrm{text}}^\star\) denote the non-ignored student and
teacher tokens that have lexical byte paths. Ignored entries are excluded from
the softmax normalizer before top-\(K_{\mathrm{TW}}\) selection.
Let
\(\mathcal{K}_{s,j}^{(b)}\subset\mathcal{V}_{s,\mathrm{text}}^\star\) and
\(\mathcal{K}_{t,j}^{(b,i)}\subset\mathcal{V}_{t,\mathrm{text}}^\star\) be the retained token
sets. The residual lexical mass assigned to the tail edge is
\begin{equation}
r_{s,j}^{(b)}
=
\sum_{v\in\mathcal{V}_{s,\mathrm{text}}^\star\setminus\mathcal{K}_{s,j}^{(b)}}
p_{s,j}^{(b)}(v),
\qquad
r_{t,j}^{(b,i)}
=
\sum_{v\in\mathcal{V}_{t,\mathrm{text}}^\star\setminus\mathcal{K}_{t,j}^{(b,i)}}
p_{t,j}^{(b,i)}(v).
\end{equation}
Let \(q_{s,j}^{(b)}\) denote the student probability assigned to non-text
tokens. For the student distribution,
\[
\sum_{v\in\mathcal{K}_{s,j}^{(b)}}p_{s,j}^{(b)}(v)
+ r_{s,j}^{(b)}
+ q_{s,j}^{(b)}
= 1,
\]
with the analogous identity for the teacher. Let \(\pi(v)\) be the trie path for token \(v\), including canonical content
edges, the EOS edge and any optional boundary edge. Let
\(e_{\mathrm{tail}}\) be the global residual tail edge with
\(w(e_{\mathrm{tail}})=1\). For any active trie edge \(e\), the sparse subtree
masses are
\begin{equation}
m_{s,j}^{(b)}(e)
=
\sum_{\substack{v\in\mathcal{K}_{s,j}^{(b)}\\e\in\pi(v)}}
p_{s,j}^{(b)}(v)
+
\mathbf{1}[e=e_{\mathrm{tail}}]\,r_{s,j}^{(b)},
\end{equation}
\begin{equation}
m_{t,j}^{(b,i)}(e)
=
\sum_{\substack{v\in\mathcal{K}_{t,j}^{(b,i)}\\e\in\pi(v)}}
p_{t,j}^{(b,i)}(v)
+
\mathbf{1}[e=e_{\mathrm{tail}}]\,r_{t,j}^{(b,i)}.
\end{equation}

\subsection{Byte-Trie Wasserstein Objective}

With the trie structure and sparse supports defined, the loss is computed as a
weighted sum of per-edge subtree-mass imbalances. Writing the dense case first
makes the formula clearest: let \(\mathcal{V}_s\) and \(\mathcal{V}_t\) denote
the full student and teacher vocabularies at a given answer position and let
\(m_s(e)\) and \(m_t(e)\) measure how much probability each distribution routes
through edge \(e\):
\[
m_s(e)
=
\sum_{\substack{v\in\mathcal{V}_s\\ e\in\pi(v)}} p_s(v),
\qquad
m_t(e)
=
\sum_{\substack{u\in\mathcal{V}_t\\ e\in\pi(u)}} p_t(u).
\]
On a tree metric, the Wasserstein distance has the closed form
\begin{equation}
W_T(p_s,p_t)
=
\sum_{e\in E}
w(e)\left|m_s(e)-m_t(e)\right|.
\label{eq:trie-wasserstein-objective}
\end{equation}

This form follows from the standard \(W_1\) Kantorovich optimal transport
problem under the trie-induced tree metric
\cite{peyre2019computationaloptimaltransport,takezawa2021supervisedtreewasserstein}.
The full proof is provided in Appendix~\ref{app:tree-wasserstein-proof}. In
training, GRACE evaluates the same per-edge formula on the sparse active edge
set defined above, using the retained token paths and residual tail edge.
The token-level Byte-Trie Wasserstein loss is
\begin{equation}
\ell_{TW}\!\left(\mathbf{z}_{s,j}^{(b)},\mathbf{z}_{t,j}^{(b,i)}\right)
=
\sum_{e\in\mathcal{E}_{act,j}^{(b,i)}}
w(e)\,
\left|
m_{s,j}^{(b)}(e)-m_{t,j}^{(b,i)}(e)
\right|
+
\lambda_{\mathrm{nt}}q_{s,j}^{(b)},
\label{eq:token_tw}
\end{equation}
where \(\mathcal{E}_{act,j}^{(b,i)}\) contains the active canonical content
edges, EOS edges, optional boundary edges and the residual tail edge from the
student and teacher supports. The \textbf{non-text penalty} with
\(\lambda_{\mathrm{nt}}\ge 0\) discourages probability mass on visual or
control tokens without assigning those tokens a lexical byte path.

The per-sample, per-teacher KD loss is the mean over supervised answer
tokens:
\begin{equation}
\mathcal{L}_{KD}^{(b,i)}
=
\frac{1}{|\Omega_{b,i}^{KD}|}
\sum_{j\in\Omega_{b,i}^{KD}}
\ell_{TW}\!\left(\mathbf{z}_{s,j}^{(b)},\mathbf{z}_{t,j}^{(b,i)}\right).
\label{eq:per_teacher_tw}
\end{equation}

The gradient of the trie term with respect to the student probability on
retained token \(v\) at position \(j\) is
\begin{equation}
\frac{\partial\,\ell_{TW}}{\partial\,p_{s,j}^{(b)}(v)}
=
\sum_{e\,\in\,\pi(v)}
w(e)\cdot\mathrm{sign}\!\left(m_{s,j}^{(b)}(e)-m_{t,j}^{(b,i)}(e)\right),
\quad v\in\mathcal{K}_{s,j}^{(b)}.
\label{eq:tw-gradient}
\end{equation}
The gradient for token \(v\) accumulates signed corrections along every edge
on its byte path. Tokens sharing a byte prefix with the teacher's
high-probability region therefore receive correlated gradient updates, nudging
the student toward semantically related strings. This \textbf{prefix-coupling} is
absent from rank-based losses such as ULD, which updates each rank position
independently of decoded string content. The tree term itself remains exact
Wasserstein transport under the trie metric, while the non-text penalty is
additive and independent of that geometry.

\textbf{Complexity Analysis.}
The shared byte trie is built once with cost
\(O(V_s\bar{L}_s + V_t\bar{L}_t)\), where \(V_s,V_t\) are the student and
teacher vocabulary sizes and \(\bar{L}_s,\bar{L}_t\) are average trie-path
lengths. During training, each aligned answer position keeps only the
top-\(K_{\mathrm{TW}}\) lexical student and teacher tokens and accumulates
probability mass along their active trie paths. The per-position cost is
\[
O\!\left((V_s+V_t)\log K_{\mathrm{TW}}
+ K_{\mathrm{TW}}(\bar{L}_s+\bar{L}_t) + A\right),
\]
where \(A\) is the number of active trie edges. Thus, sparse Byte-Trie Wasserstein
matching avoids materializing the dense \(|V_s|\times |V_t|\) optimal-transport
matrix. The approximation error relative to the dense loss is bounded by the
total unretained mass: since all edge weights satisfy \(w(e)\le 1\) and
reassigning unretained mass to the tail edge changes each edge contribution by
at most one unit,
\begin{equation}
\left|\ell_{TW}^{\mathrm{sparse}}-\ell_{TW}^{\mathrm{dense}}\right|
\le
r_{s,j}^{(b)}+r_{t,j}^{(b,i)}.
\label{eq:tw-sparse-error}
\end{equation}
The bound becomes small when \(K_{\mathrm{TW}}\) is large enough that the tail
masses are small and it vanishes when the retained set covers the full
vocabulary.

\section{Teacher Routing Network}
\label{sec:teacher-routing-network}

With the cross-tokenizer loss defined, GRACE next decides which teachers to
activate for each training sample. Uniform teacher averaging ignores how each
teacher performs across different samples. GRACE therefore uses a
\textbf{student-conditioned router} to propose a small teacher set per sample.
Figure~\ref{fig:deep-router} shows the full routing pipeline
\cite{shazeer2017outrageouslylargeneuralnetworks,fedus2022switchtransformersscalingtrillion,yuan2020reinforcedmultiteacherselection}.

\begin{figure}
\centering
\includegraphics[width=\linewidth]{figures/deep-router.pdf}
\caption{Teacher routing network.}
\label{fig:deep-router}
\end{figure}

Let \(\mathbf{H}_s^{(b)}\) be the student hidden states before the language-model
head. GRACE pools the supervised answer positions to obtain the routing feature
\[
\mathbf{h}^{(b)}=\mathrm{Pool}(\mathbf{H}_s^{(b)}).
\]
\textbf{Answer-position pooling} restricts the routing feature to the supervised span,
so the router conditions on a representation that mixes visual context,
question text and answer content, which jointly determine which teacher is most
useful for a given sample.

A learned \textbf{MLP router} \(G_{\phi}(\cdot)\) maps this feature to teacher logits
and soft weights:
\[
\mathbf{r}^{(b)}=G_{\phi}(\mathbf{h}^{(b)}),
\qquad
\mathbf{p}^{(b)}=\mathrm{softmax}(\mathbf{r}^{(b)}).
\]
Concretely, \(G_{\phi}\) is a \textbf{gated MLP} with a SwiGLU-style block. The
hidden projection is split into a \textit{value} branch and a \textit{gate}
branch and their element-wise product
\(\mathrm{SiLU}(\mathbf{g})\odot\mathbf{v}\) forms the routing
representation before the final linear head.
A plain linear projection cannot capture the non-linear feature interactions
that determine teacher usefulness because whether a particular teacher is the best
supervisor depends on joint patterns in \(\mathbf{h}^{(b)}\), such as the
image being chart-heavy \textit{and} the question requesting a numerical
value, not on either cue alone.
The gating mechanism addresses this directly: one branch creates a rich
intermediate representation from the student hidden state and the other
branch learns which dimensions of that representation are actually relevant
for the routing decision, suppressing irrelevant features rather than
propagating them.
The router then keeps the top-\(k_{\mathrm{route}}\) teachers:
\[
\mathcal{R}_b=\mathrm{TopK}(\mathbf{r}^{(b)},\min(k_{\mathrm{route}},N)).
\]
Hard selection is used rather than a soft threshold because keeping
low-weight teachers still requires computing the full Byte-Trie Wasserstein
loss for each one. Eliminating them entirely removes their noise from the
distillation signal rather than merely downweighting it.
Weights outside \(\mathcal{R}_b\) are zeroed and the rest renormalized:
\begin{equation}
\hat{p}_i^{(b)}
=
\frac{\mathbf{1}[i\in\mathcal{R}_b] p_i^{(b)}}
{\sum_{j=1}^{N}\mathbf{1}[j\in\mathcal{R}_b] p_j^{(b)}}.
\label{eq:constrained_gate_weights}
\end{equation}
Because \(\mathbf{h}^{(b)}\) reflects the current student hidden states,
the routed set \(\mathcal{R}_b\) changes as the student evolves, so teacher
selection adapts to both input content and the current student state.
Top-\(k\) routing also limits the active teacher set to
\(k_{\mathrm{route}}\) candidates and separates candidate selection from final
weighting: the router proposes teachers by input relevance and
Section~\ref{sec:gradient-agreement} adjusts their weights by gradient
compatibility.

The effect of top-\(k\) routing across eight samples and four teachers is
visible in Figure~\ref{fig:grace-routing-dynamics}. In the leftmost heatmap,
\(T_1\) consistently receives the highest soft gate weight, followed by
\(T_2\), while \(T_3\) and \(T_4\) remain low throughout. The top-\(k\)
mask (second panel) retains only \(T_1\) and \(T_2\) for all samples,
zeroing the rest. After renormalization, the routed weights
\(\hat{\mathbf{p}}^{(b)}\) (third panel) are split between \(T_1\) and
\(T_2\), with \(T_1\) holding the majority. The bar chart on the right
confirms that \(T_1\) and \(T_2\) capture all routing assignments in this
mini-batch, while \(T_3\) and \(T_4\) receive none.

\begin{figure}
    \centering
    \includegraphics[width=0.78\linewidth]{figures/grace_routing_dynamics.png}
    \caption[Top-\(k\) routing dynamics.]{Top-\(k\) routing dynamics.}
    \label{fig:grace-routing-dynamics}
\end{figure}

Hard top-\(k\) selection can cause the router to \textbf{collapse onto a single teacher}
if left unconstrained, so GRACE uses entropy and \(z\)-loss stabilizers. The
entropy term discourages premature \textbf{routing collapse}
\cite{shazeer2017outrageouslylargeneuralnetworks,fedus2022switchtransformersscalingtrillion}:
\begin{equation}
\mathcal{L}_{ent}
=
-\frac{1}{B}\sum_{b=1}^{B} H(\mathbf{p}^{(b)}).
\end{equation}
The \(z\)-loss penalizes large router logit magnitudes:
\begin{equation}
\mathcal{L}_{z}
=
\frac{1}{B}\sum_{b=1}^{B}
\left(\log \sum_{i=1}^{N} e^{r_i^{(b)}}\right)^2.
\end{equation}
These auxiliary losses stabilize teacher selection, while CE and routed KD remain
the main training signals.

\section{Gradient-Agreement Refinement}
\label{sec:gradient-agreement}
\label{sec:gradient-agreement-refinement}

Routing proposes teachers relevant to each sample, but a selected teacher may still
produce a KD gradient that conflicts with the supervised CE objective. GRACE computes one agreement score per teacher per mini-batch and uses it to
reweight each sample's routed teachers.

\subsection{Agreement Score Computation}
\label{sec:agreement-score-computation}

Let \(\mathbf{g}_{CE}=\nabla_{\Theta}\mathcal{L}_{CE}\) be the supervised
gradient over trainable student parameters \(\Theta\). For teacher \(T_i\),
GRACE averages its KD loss over the mini-batch to get
\[
\mathbf{g}_{i}
=
\nabla_{\Theta}
\left(
\frac{1}{B}\sum_{b=1}^{B}
\mathcal{L}_{KD}^{(b,i)}\right),
\]
where \(\mathcal{L}_{KD}^{(b,i)}\) is the Byte-Trie Wasserstein loss from
Equation~\ref{eq:per_teacher_tw}. The raw \textbf{agreement score} is the cosine
similarity
\begin{equation}
s_i
=
\frac{
\langle \mathbf{g}_{CE},\mathbf{g}_i\rangle
}{
\max\!\left(\|\mathbf{g}_{CE}\|_2\|\mathbf{g}_i\|_2,\epsilon_{\mathrm{num}}\right)
}.
\label{eq:grace-gradient-agreement-score}
\end{equation}
Cosine similarity is well-suited to this comparison: both losses optimize
the same parameters and the normalization removes teacher-to-teacher scale
differences. This is clearest from a first-order expansion of one gradient
step with routed KD:
\[
\Delta\theta
=
-\eta
\left(
\mathbf{g}_{CE}
+
\alpha_{\mathrm{KD}}\sum_i w_i \mathbf{g}_i
\right).
\]
The first-order change in the supervised CE loss is
\[
\Delta\mathcal{L}_{CE}
\approx
\mathbf{g}_{CE}^{\top}\Delta\theta
=
-\eta\|\mathbf{g}_{CE}\|_2^2
-
\eta\alpha_{\mathrm{KD}}\sum_i w_i
\langle \mathbf{g}_{CE},\mathbf{g}_i\rangle .
\]
When \(\langle \mathbf{g}_{CE},\mathbf{g}_i\rangle>0\), teacher \(T_i\)'s KD
direction \textbf{supports} the supervised CE update. When the inner product is
negative, the teacher \textbf{pushes against} the supervised CE objective. Under the
simplex constraints \(w_i\ge 0\) and \(\sum_i w_i=1\), the unregularized
first-order objective would place all KD weight on the routed teacher with the
largest inner product \(\langle \mathbf{g}_{CE},\mathbf{g}_i\rangle\). GRACE uses cosine agreement instead, comparing \textbf{gradient directions and not
magnitudes}. The score-softmax gives a smooth relaxation of the hard
winner-take-all selection. Gradient agreement thus serves both roles:
\textbf{filtering conflicting teachers} and \textbf{up-weighting} those whose KD direction aligns
with the CE update
\cite{yu2020gradient}. Each \(s_i\) is computed once per mini-batch at the teacher level and per-sample
variation arises through intersection with each sample's routed set
\(\mathcal{R}_b\).

\subsection{Warmup, EMA Smoothing and Active Set}
\label{sec:agreement-smoothing-active-set}

During \textbf{warmup} (the first \(\rho_g T_{\mathrm{train}}\) steps), routed weights
are used unchanged: \(w_i^{(b)}=\hat{p}_i^{(b)}\). Agreement scoring is
skipped early because an unstable student produces scores too noisy to be
useful for filtering. After warmup, the raw score is first thresholded:
\[
\tilde{a}_i=\mathbf{1}[s_i>\delta],
\]
then smoothed with \textbf{EMA}:
\[
\hat{s}_i
=
\beta_{\mathrm{EMA}}\hat{s}^{\mathrm{prev}}_i
+
(1-\beta_{\mathrm{EMA}})s_i.
\]
A single mini-batch score is too noisy to be a reliable filter: a teacher
that is consistently aligned may produce a negative score on one batch
purely due to sampling variation. EMA accumulates a smoothed signal across
steps so that filtering reflects a teacher's sustained directional tendency
rather than reacting to individual batch fluctuations.
In short, \(s_i\) captures the current-batch gradient direction and drives the
threshold test, while \(\hat{s}_i\) accumulates a smoothed estimate across steps
and drives the final weighting. Figure~\ref{fig:grace-ema-smoothing} illustrates
both effects. The left panel shows that the per-batch score (orange) oscillates
widely across training steps, while the EMA (blue) tracks a smooth, slowly-moving
trend. The centre panel compares the current \(s_i\) and smoothed \(\hat{s}_i\)
across four teachers for one step: \(T_4\) has a near-zero or negative current
score that would suppress it if used directly, but its smoothed score remains
slightly positive, reflecting recent history. The right panel shows the
consequence for weighting: using raw batch scores concentrates almost all gradient
weight on a single teacher, while using smoothed scores distributes weight more
evenly across the active set, preventing a single noisy batch from dominating
teacher selection.

\begin{figure}[!htbp]
    \centering
    \includegraphics[width=0.96\linewidth]{figures/grace_ema_smoothing.png}
    \caption[EMA smoothing.]{EMA smoothing.}
    \label{fig:grace-ema-smoothing}
\end{figure}

With smoothed scores in hand, GRACE constructs a \textbf{per-sample active set} by
intersecting the threshold flag \(\tilde{a}_i\) with the routed set:
\begin{equation}
\mathcal{A}_b=\{i\in\mathcal{R}_b:\tilde{a}_i=1\}.
\label{eq:grace-sample-active-set}
\end{equation}
Finally, the smoothed scores pass a softmax over \(\mathcal{A}_b\) to
produce agreement weights \(\omega\):
\begin{equation}
\omega_i^{(b)}
=
\frac{
\exp(\beta_{\mathrm{score}}\hat{s}_i) \mathbf{1}[i \in \mathcal{A}_b]
}{
\sum_{j=1}^{N}
\exp(\beta_{\mathrm{score}}\hat{s}_j) \mathbf{1}[j \in \mathcal{A}_b]
},
\label{eq:grace_softmax}
\end{equation}
These agreement weights \(\omega_i^{(b)}\) must then be combined with the
router's relevance scores \(\hat{p}_i^{(b)}\). Three edge cases, an empty
active set, nearly tied scores and a clear winner, each call for a different
rule.

\subsection{Fallback, Uniform and Blended Weighting}
\label{sec:agreement-weighting-rule}

The final rule, summarized in Figure~\ref{fig:grace-score-refinement}, chooses
among three cases, each handling a failure mode the others cannot.
If \(\mathcal{A}_b\) is empty, every selected teacher is conflicting and
there is no agreement signal to use. GRACE \textbf{falls back} to the
routed weights \(\hat{p}^{(b)}\) because they still reflect input-level
relevance and training must continue.
If the spread between the maximum and minimum agreement scores inside
\(\mathcal{A}_b\) is below \(\epsilon_{\mathrm{fb}}\) (so the active
teachers are nearly tied), acting on small score differences would amplify
noise into meaningless weight differences. GRACE therefore uses
\textbf{uniform weights} over \(\mathcal{A}_b\) as the more robust choice.
Otherwise, when the agreement signal is strong enough to differentiate
teachers, it \textbf{geometrically blends} the routed weights \(\hat{p}\) and the
agreement weights \(\omega\):
\begin{equation}
w_i^{(b)}
=
\frac{(\hat{p}_i^{(b)})^{\lambda_{\mathrm{blend}}}
(\omega_i^{(b)})^{1-\lambda_{\mathrm{blend}}}
\,\mathbf{1}[i\in\mathcal{A}_b]}
{\sum_{j=1}^{N}(\hat{p}_j^{(b)})^{\lambda_{\mathrm{blend}}}
(\omega_j^{(b)})^{1-\lambda_{\mathrm{blend}}}
\,\mathbf{1}[j\in\mathcal{A}_b]}.
\label{eq:effective_teacher_weights}
\end{equation}
Here, \(\lambda_{\mathrm{blend}}\in[0,1]\) interpolates between pure score
weighting and pure router weighting.
The geometric form is deliberate: because the two terms are multiplied
rather than added, a teacher with near-zero weight under either signal is
suppressed in the final weight regardless of how high the other signal is.
An arithmetic blend would allow a highly gradient-aligned teacher to be
included despite low routing relevance, or vice versa.
The geometric blend requires both signals to agree, with
\(\lambda_{\mathrm{blend}}\) controlling how much each signal contributes
to that joint decision.

    \caption[GRACE score refinement.]{GRACE score refinement.}
    \label{fig:grace-score-refinement}
\end{figure}

The three panels of Figure~\ref{fig:grace-score-refinement} step through the
refinement pipeline in order. On the left, the gradient-direction diagram

entirely. On the right, the two non-fallback outcomes are contrasted: when

shifts the final weight toward the gradient-preferred teacher. When the
spread is below the threshold, all active teachers receive equal final

\section{Routed KD Aggregation and Final Objective}
\label{sec:routed-kd-final-objective}

The three components described in the preceding sections, Byte-Trie
Wasserstein matching, sparse routing and gradient-agreement refinement,
each produce a per-teacher, per-sample quantity: a loss value
$\mathcal{L}_{KD}^{(b,i)}$ and a final weight $w_i^{(b)}$. Gradient-agreement
refinement restricts these weights to the routed set $\mathcal{R}_b$, so each
sample draws on at most $k_{\mathrm{route}}$ teachers. This section combines
both quantities into a single training objective whose key property is that
$w_i^{(b)}$ is \textbf{sample-specific}, allowing different examples in the same
mini-batch to draw on different teachers.

At the sample level, only teachers in the routed set $\mathcal{R}_b$ contribute
to the KD loss:
\begin{equation}
\bar{\mathcal{L}}_{KD}^{(b)}
=
\sum_{i\in\mathcal{R}_b} w_i^{(b)}\mathcal{L}_{KD}^{(b,i)},
\label{eq:sample-kd}
\end{equation}
where $w_i^{(b)}$ reflects whichever of the three weighting rules applies
(fallback, uniform or blended). The mini-batch KD term averages these:
\[
\mathcal{L}_{KD}
=
B^{-1}\sum_{b=1}^{B}\bar{\mathcal{L}}_{KD}^{(b)}.
\]
Because \(w_i^{(b)}\) is computed per sample, different examples in the same
mini-batch can emphasize different teachers.
Figure~\ref{fig:grace-sample-specific-weighting} shows this for text-heavy,
chart-heavy and ambiguous samples.

\begin{figure}[!htbp]
    \centering
    \includegraphics[width=\linewidth]{figures/grace_sample_specific_weighting.png}
    \caption[Sample-specific weighting.]{Sample-specific weighting.}
    \label{fig:grace-sample-specific-weighting}
\end{figure}

Each panel compares the routed weight \(\hat{p}\) (blue) with the final
weight \(w\) (green) across four teachers. For the text-heavy sample,
\(T_1\) is already the top router choice and gradient agreement amplifies
it further, while the lower-ranked teachers are suppressed. For the
chart-heavy sample, \(T_3\) is preferred by the router and agreement
reinforces this, shifting the dominant teacher away from \(T_1\). For the
ambiguous sample, the router weights are spread across all four teachers
and the agreement scores provide no strong signal, so the final weights
remain close to the routed weights with no single teacher dominating.

\FloatBarrier

The complete \methodname{} objective is
\begin{equation}
\mathcal{L}
=
\mathcal{L}_{CE}
+
\alpha_{\mathrm{KD}}\mathcal{L}_{KD}
+
\lambda_{\mathrm{ent}}\mathcal{L}_{ent}
+
\lambda_{z}\mathcal{L}_{z},
\label{eq:final-objective}
\end{equation}
where $\mathcal{L}_{CE}$ anchors the student to supervised answer tokens,
$\mathcal{L}_{KD}$ transfers routed teacher supervision and $\mathcal{L}_{ent}$
together with $\mathcal{L}_{z}$ regularize the router, while teacher parameters
remain frozen throughout. Together, the four terms directly address
the three constraints from the opening of this chapter: $\mathcal{L}_{KD}$
handles \textbf{tokenizer mismatch} through the byte-trie loss, the routing weights
inside it handle \textbf{per-sample teacher relevance} and the gradient-agreement
scores that set those weights handle \textbf{optimization conflict}.

\begin{algorithm}[H]
\caption{One GRACE training step}
\label{alg:grace-training-step}
\begin{algorithmic}[1]
\Require Mini-batch \(\mathcal{B}=\{(x_b,y_b)\}_{b=1}^{B}\), frozen teachers
\(\{T_i\}_{i=1}^{N}\), student \(S_\theta\), router \(G_\phi\)
\State Run the student on \(\mathcal{B}\) to obtain logits
\(\mathbf{z}_s^{(b)}\), hidden states \(\mathbf{H}_s^{(b)}\) and supervised
loss \(\mathcal{L}_{CE}\)
\For{each sample \(b\)}
    \State Pool hidden states at answer positions to form \(\mathbf{h}^{(b)}\)
    \State Compute router logits
    \(\mathbf{r}^{(b)}=G_\phi(\mathbf{h}^{(b)})\) and probabilities
    \(\mathbf{p}^{(b)}=\mathrm{softmax}(\mathbf{r}^{(b)})\)
    \State Select routed set
    \(\mathcal{R}_b=\mathrm{TopK}(\mathbf{r}^{(b)},\min(k_{\mathrm{route}},N))\)
    \State Renormalize routed weights to obtain \(\hat{\mathbf{p}}^{(b)}\)
\EndFor
\For{each teacher \(T_i\) selected by at least one sample}
    \State Load cached teacher logits \(\mathbf{z}_t^{(b,i)}\)
    \State Compute \(\mathcal{L}_{KD}^{(b,i)}\) with Byte-Trie Wasserstein
    matching on aligned answer positions
    \State Compute teacher-level gradient \(\mathbf{g}_i\) and agreement score
    \(s_i\)
\EndFor
\State Smooth agreement scores with EMA and construct active sets
\(\mathcal{A}_b\)
\State Compute final teacher weights \(w_i^{(b)}\) using fallback,
uniform or geometric blend rules
\State Aggregate routed KD for each sample
\Statex \[
\bar{\mathcal{L}}_{KD}^{(b)}
=
\sum_{i\in\mathcal{R}_b}w_i^{(b)}\mathcal{L}_{KD}^{(b,i)}
\]
\State Optimize the final objective
\Statex \[
\mathcal{L}
=
\mathcal{L}_{CE}
+
\alpha_{\mathrm{KD}}\frac{1}{B}\sum_{b=1}^{B}\bar{\mathcal{L}}_{KD}^{(b)}
+
\lambda_{\mathrm{ent}}\mathcal{L}_{ent}
+
\lambda_z\mathcal{L}_z
\]
\end{algorithmic}
\end{algorithm}
